# Chapter 05 — Operators

---

# اهداف فصل

پس از پایان این فصل انتظار می‌رود بتوانید:

- مفهوم **Operator** و **Operand** را به‌درستی توضیح دهید.
- تفاوت میان **Expression** و **Statement** را درک کنید.
- بدانید JavaScript چگونه عملیات مختلف را روی داده‌ها انجام می‌دهد.
- عملگرهای حسابی را به‌درستی در برنامه‌های واقعی به‌کار ببرید.
- مفهوم **Operator Precedence** را در سطح مقدماتی درک کنید.
- دلیل وجود عملگرهای مختلف را از دیدگاه طراحی زبان تحلیل کنید.

---

# مقدمه

تا اینجا با دو مفهوم بنیادی در JavaScript آشنا شدیم:

- **Value**
- **Variable**

اکنون می‌توانیم داده‌ها را در حافظه ذخیره کنیم.

اما سؤال مهم این است:

اگر داده‌ای در اختیار داشته باشیم، چگونه می‌توانیم روی آن عملی انجام دهیم؟

برای مثال:

- دو عدد را جمع کنیم.
- دو مقدار را با هم مقایسه کنیم.
- نتیجه یک شرط را بررسی کنیم.
- مقدار جدیدی داخل یک متغیر قرار دهیم.

تمام این کارها توسط **Operator**ها انجام می‌شوند.

به همین دلیل، عملگرها یکی از مهم‌ترین اجزای هر زبان برنامه‌نویسی محسوب می‌شوند.

تقریباً هیچ برنامه JavaScript وجود ندارد که از Operator استفاده نکند.

---

# Operator چیست؟

**Operator** نمادی است که عملی مشخص را روی یک یا چند مقدار انجام می‌دهد.

برای مثال:

```javascript
10 + 5
```

در این عبارت، علامت `+` یک Operator است.

وظیفه آن جمع کردن دو مقدار است.

یا در مثال زیر:

```javascript
age = 25;
```

علامت `=` نیز یک Operator است.

اما برخلاف تصور بسیاری از افراد، این علامت به معنای مساوی بودن نیست؛ بلکه به معنای **Assignment** یا انتساب مقدار است.

---

## تعریف ساده

Operator ابزاری است که عملی مشخص را روی داده‌ها انجام می‌دهد.

---

## تعریف فنی

Operator نماد یا کلمه‌ای است که یک عملیات تعریف‌شده را روی یک یا چند Operand اعمال می‌کند و معمولاً نتیجه‌ای جدید تولید می‌کند.

---

# Operand چیست؟

مقادیر یا متغیرهایی که یک Operator روی آن‌ها عمل می‌کند، **Operand** نام دارند.

در مثال زیر:

```javascript
10 + 5
```

عددهای:

```text
10
```

و

```text
5
```

هر دو Operand هستند.

در مثال زیر نیز:

```javascript
price * quantity
```

دو متغیر `price` و `quantity` Operand محسوب می‌شوند.

---

# Expression چیست؟

یکی از مفاهیمی که در مستندات JavaScript و همچنین دوره Jonas بارها با آن روبه‌رو می‌شویم، **Expression** است.

Expression به هر قطعه کدی گفته می‌شود که در نهایت یک مقدار تولید کند.

برای مثال:

```javascript
2 + 3
```

نتیجه این عبارت:

```text
5
```

است.

پس این کد یک Expression محسوب می‌شود.

مثال دیگر:

```javascript
2026 - 1995
```

خروجی:

```text
31
```

باز هم یک Expression است.

حتی یک مقدار ساده نیز یک Expression محسوب می‌شود.

```javascript
42
```

یا

```javascript
true
```

یا

```javascript
'JavaScript'
```

همگی Expression هستند.

زیرا در نهایت یک مقدار تولید می‌کنند.

---

# Statement چیست؟

گاهی برنامه‌نویسان Expression و Statement را با یکدیگر اشتباه می‌گیرند.

اما این دو مفهوم یکسان نیستند.

Statement دستوری است که کاری را انجام می‌دهد.

برای مثال:

```javascript
if (age >= 18) {
  console.log('Adult');
}
```

این کد یک Statement است.

زیرا عملی را اجرا می‌کند.

در حالی که شرط داخل آن:

```javascript
age >= 18
```

یک Expression است.

چون نتیجه آن مقدار بولی (`true` یا `false`) خواهد بود.

---

# چرا تفاوت Expression و Statement مهم است؟

در بسیاری از قسمت‌های JavaScript تنها استفاده از Expression مجاز است.

برای مثال:

```javascript
const result = 10 + 5;
```

سمت راست باید یک Expression باشد.

اما نوشتن:

```javascript
const result = if (...) {};
```

امکان‌پذیر نیست.

درک این تفاوت بعدها هنگام یادگیری Arrow Function، Ternary Operator و JSX اهمیت بسیار زیادی پیدا خواهد کرد.

---

# اولین گروه عملگرها

Operator های JavaScript در گروه‌های مختلفی قرار می‌گیرند.

مهم‌ترین آن‌ها عبارت‌اند از:

- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Logical Operators
- Unary Operators
- Conditional Operator

در این بخش، با ساده‌ترین و پرکاربردترین گروه یعنی **Arithmetic Operators** آشنا می‌شویم.

---

# Arithmetic Operators

عملگرهای حسابی برای انجام محاسبات ریاضی استفاده می‌شوند.

مهم‌ترین آن‌ها عبارت‌اند از:

| Operator | Description |
|----------|-------------|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `%` | باقیمانده تقسیم |
| `**` | توان |

---

## مثال

```javascript
const a = 10;
const b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);
```

خروجی:

```text
13
7
30
3.333...
1
1000
```

---

# عملگر باقیمانده (`%`)

یکی از عملگرهایی که در ابتدا کمتر مورد توجه قرار می‌گیرد، عملگر باقیمانده است.

```javascript
10 % 3
```

نتیجه:

```text
1
```

زیرا:

```text
10 = 3 × 3 + 1
```

این عملگر در پروژه‌های واقعی کاربردهای فراوانی دارد.

برای مثال:

- تشخیص زوج یا فرد بودن عدد
- ایجاد الگوهای تکرارشونده
- صفحه‌بندی (Pagination)
- بازی‌ها
- زمان‌بندی

در فصل‌های بعد بارها از این عملگر استفاده خواهیم کرد.

---

# دیدگاه Jonas

Jonas در ابتدای آموزش JavaScript تأکید می‌کند که برنامه‌نویسی تنها حفظ کردن سینتکس نیست.

او معتقد است:

> **Operatorها ابزارهایی هستند که منطق برنامه را می‌سازند.**

هرچه درک عمیق‌تری از رفتار Operatorها داشته باشید، نوشتن الگوریتم‌ها ساده‌تر خواهد شد.

به همین دلیل، پیش از ورود به مباحث پیچیده‌تر، باید رفتار پایه‌ای آن‌ها را کاملاً درک کنید.

---

# اشتباه رایج

بسیاری از افراد تصور می‌کنند:

```javascript
=
```

علامت مساوی است.

در حالی که در JavaScript این علامت معمولاً **Assignment Operator** است، نه عملگر برابری.

در بخش بعد خواهیم دید که JavaScript برای مقایسه واقعی از عملگرهای دیگری استفاده می‌کند.

---

# نکات مهم

- Operator عملی را روی داده‌ها انجام می‌دهد.
- Operand داده‌ای است که عملگر روی آن اجرا می‌شود.
- هر Expression در نهایت یک مقدار تولید می‌کند.
- هر Statement الزاماً مقدار تولید نمی‌کند.
- عملگرهای حسابی اولین و پرکاربردترین گروه Operatorها هستند.
- عملگر `%` تنها برای محاسبه باقیمانده نیست و در بسیاری از الگوریتم‌های واقعی کاربرد دارد.

---
---

# Assignment Operators

در بخش قبل با عملگرهای حسابی آشنا شدیم و دیدیم که چگونه می‌توان روی داده‌ها عملیات ریاضی انجام داد.

اما یک سؤال مهم همچنان باقی مانده است.

اگر نتیجه یک محاسبه را به دست آوریم، چگونه آن را داخل یک متغیر ذخیره کنیم؟

برای پاسخ به این سؤال، JavaScript گروه دیگری از عملگرها را در اختیار ما قرار می‌دهد که **Assignment Operators** یا **عملگرهای انتساب** نام دارند.

---

# Assignment چیست؟

در زبان انگلیسی، واژه **Assignment** به معنای «اختصاص دادن» یا «واگذار کردن» است.

در JavaScript نیز دقیقاً همین اتفاق رخ می‌دهد.

```javascript
let score = 100;
```

در این مثال، مقدار `100` به متغیر `score` اختصاص داده شده است.

بنابراین:

```javascript
=
```

در اینجا به معنای **برابر بودن** نیست.

بلکه به معنای **قرار دادن یک مقدار درون یک متغیر** است.

این موضوع یکی از اولین تفاوت‌های میان ریاضیات و برنامه‌نویسی است.

---

# تفاوت "=" در ریاضیات و برنامه‌نویسی

در ریاضیات:

```text
x = x + 1
```

عبارت بالا اشتباه است.

زیرا هیچ عددی وجود ندارد که یک واحد از خودش بزرگ‌تر باشد.

اما در JavaScript:

```javascript
let x = 5;

x = x + 1;
```

کاملاً صحیح است.

ابتدا مقدار سمت راست محاسبه می‌شود.

```javascript
5 + 1
```

نتیجه:

```text
6
```

سپس مقدار جدید داخل متغیر `x` قرار می‌گیرد.

در نتیجه:

```javascript
console.log(x);
```

خروجی:

```text
6
```

خواهد بود.

بنابراین باید این مدل ذهنی را همیشه به خاطر داشته باشید:

> علامت `=` در JavaScript به معنای **کپی کردن مقدار سمت راست در متغیر سمت چپ** است.

---

# رایج‌ترین Assignment Operator

ساده‌ترین عملگر انتساب همان علامت `=` است.

```javascript
let age = 30;
```

اما JavaScript عملگرهای ترکیبی دیگری نیز دارد که باعث کوتاه‌تر و خواناتر شدن کد می‌شوند.

---

# Compound Assignment Operators

فرض کنید بخواهیم مقدار یک متغیر را افزایش دهیم.

می‌توانیم بنویسیم:

```javascript
count = count + 1;
```

اما JavaScript شکل کوتاه‌تر این دستور را نیز فراهم کرده است.

```javascript
count += 1;
```

هر دو دستور دقیقاً نتیجه یکسانی دارند.

---

## مهم‌ترین عملگرهای ترکیبی

| Operator | معادل |
|----------|--------|
| `+=` | `x = x + value` |
| `-=` | `x = x - value` |
| `*=` | `x = x * value` |
| `/=` | `x = x / value` |
| `%=` | `x = x % value` |
| `**=` | `x = x ** value` |

---

## مثال

```javascript
let balance = 100;

balance += 50;

console.log(balance);
```

خروجی:

```text
150
```

یا:

```javascript
let score = 20;

score *= 2;

console.log(score);
```

خروجی:

```text
40
```

---

# Increment Operator

یکی از پرکاربردترین عملیات‌ها در برنامه‌نویسی، افزایش مقدار یک متغیر به اندازه یک واحد است.

برای این کار می‌توان نوشت:

```javascript
count = count + 1;
```

یا:

```javascript
count += 1;
```

اما JavaScript یک عملگر اختصاصی نیز برای این کار دارد.

```javascript
count++;
```

این عملگر را **Increment Operator** می‌نامند.

---

## مثال

```javascript
let count = 5;

count++;

console.log(count);
```

خروجی:

```text
6
```

---

# Decrement Operator

برعکس عملگر قبلی نیز وجود دارد.

```javascript
count--;
```

این دستور مقدار متغیر را یک واحد کاهش می‌دهد.

```javascript
let lives = 3;

lives--;

console.log(lives);
```

خروجی:

```text
2
```

---

# آیا همیشه باید از ++ استفاده کنیم؟

از نظر عملکرد، این دو دستور تقریباً معادل هستند.

```javascript
count++;

count += 1;
```

اما در پروژه‌های بزرگ، بسیاری از توسعه‌دهندگان ترجیح می‌دهند از شکل دوم استفاده کنند.

دلیل آن خوانایی بیشتر و کاهش ابهام در برخی شرایط است.

به همین دلیل، در بسیاری از Style Guideهای مدرن مشاهده می‌شود که استفاده از `+= 1` نسبت به `++` ترجیح داده شده است.

# دیدگاه Jonas

Jonas Schmedtmann در مثال‌های آموزشی خود از هر دو روش استفاده می‌کند، اما تأکید می‌کند که مهم‌تر از حفظ کردن سینتکس، درک رفتار Assignment است.

به اعتقاد او، بسیاری از خطاهای مبتدیان از اینجا آغاز می‌شود که تصور می‌کنند علامت `=` همان مفهوم ریاضی را دارد.

در حالی که در JavaScript این عملگر تنها یک وظیفه دارد:

> اختصاص دادن نتیجه عبارت سمت راست به متغیر سمت چپ.

# اشتباهات رایج

❌

```javascript
x = x + 1;
```

یعنی بررسی می‌کند که آیا دو طرف برابر هستند.

✔

این دستور مقدار جدیدی را داخل متغیر `x` قرار می‌دهد.

---

❌

```javascript
count++;
```

یک عملگر ریاضی است.

✔

این دستور نیز نوعی Assignment محسوب می‌شود، زیرا مقدار جدیدی را در همان متغیر ذخیره می‌کند.

---

# نکات مهم

- عملگر `=` برای مقایسه استفاده نمی‌شود.
- Assignment همیشه مقدار جدیدی را داخل متغیر قرار می‌دهد.
- عملگرهای `+=`، `-=`, `*=`, `/=` نسخه کوتاه‌شده Assignment هستند.
- عملگرهای `++` و `--` برای افزایش یا کاهش یک واحدی مقدار متغیر استفاده می‌شوند.
- درک صحیح Assignment یکی از پایه‌های فهم JavaScript و بسیاری از زبان‌های برنامه‌نویسی است.

# Comparison Operators

در دو بخش قبل با دو گروه مهم از عملگرها آشنا شدیم.

ابتدا دیدیم که **Arithmetic Operators** برای انجام محاسبات ریاضی استفاده می‌شوند و سپس آموختیم که **Assignment Operators** نتیجه محاسبات را داخل متغیرها ذخیره می‌کنند.

اما هنوز یک سؤال اساسی باقی مانده است.

اگر بخواهیم تصمیم بگیریم چه اتفاقی در برنامه رخ دهد، چگونه باید دو مقدار را با یکدیگر مقایسه کنیم؟

برای مثال:

- آیا سن کاربر بیشتر از ۱۸ سال است؟
- آیا موجودی حساب کافی است؟
- آیا رمز عبور صحیح وارد شده است؟
- آیا دو مقدار با یکدیگر برابر هستند؟

تمام این پرسش‌ها توسط **Comparison Operators** پاسخ داده می‌شوند.

---

# Comparison Operator چیست؟

Comparison Operator یا **عملگر مقایسه**، دو مقدار را با یکدیگر مقایسه می‌کند و نتیجه این مقایسه همیشه یک مقدار بولی خواهد بود.

یعنی خروجی آن فقط یکی از دو مقدار زیر است:

```javascript
true
```

یا

```javascript
false
```

---

## تعریف ساده

Comparison Operator دو مقدار را با یکدیگر مقایسه می‌کند.

---

## تعریف فنی

Comparison Operator رابطه میان دو Operand را بررسی کرده و نتیجه‌ای از نوع Boolean تولید می‌کند.

---

# مهم‌ترین عملگرهای مقایسه

| Operator | Description |
|----------|-------------|
| `>` | بزرگ‌تر |
| `<` | کوچک‌تر |
| `>=` | بزرگ‌تر یا مساوی |
| `<=` | کوچک‌تر یا مساوی |
| `==` | برابری (Loose Equality) |
| `===` | برابری دقیق (Strict Equality) |
| `!=` | نابرابری |
| `!==` | نابرابری دقیق |

---

# عملگرهای بزرگ‌تر و کوچک‌تر

ساده‌ترین عملگرهای مقایسه عبارت‌اند از:

```javascript
>
```

و

```javascript
<
```

مثال:

```javascript
20 > 18
```

خروجی:

```text
true
```

یا

```javascript
10 < 5
```

خروجی:

```text
false
```

این عملگرها در پروژه‌های واقعی بسیار پرکاربرد هستند.

برای مثال:

```javascript
if (balance > price) {

}
```

---

# عملگرهای >= و <=

گاهی لازم است علاوه بر بزرگ‌تر یا کوچک‌تر بودن، حالت مساوی نیز در نظر گرفته شود.

برای مثال:

```javascript
age >= 18
```

اگر سن کاربر ۱۸ باشد، نتیجه:

```text
true
```

خواهد بود.

---

# Equality Operators

بخش مهم‌تر Comparison Operatorها، بررسی برابری دو مقدار است.

JavaScript دو نوع عملگر برای این کار دارد.

```javascript
==
```

و

```javascript
===
```

در نگاه اول ممکن است این دو کاملاً مشابه به نظر برسند.

اما رفتار آن‌ها کاملاً یکسان نیست.

---

# Loose Equality (`==`)

عملگر `==` تنها مقدارها را مقایسه نمی‌کند.

در بسیاری از شرایط، ابتدا تلاش می‌کند نوع داده‌ها را به یکدیگر تبدیل کند.

به این فرایند **Type Coercion** گفته می‌شود.

مثال:

```javascript
5 == '5'
```

خروجی:

```text
true
```

چرا؟

زیرا JavaScript رشته `'5'` را به عدد تبدیل می‌کند و سپس دو مقدار را مقایسه می‌کند.

---

# Strict Equality (`===`)

عملگر `===` هیچ تبدیل خودکاری انجام نمی‌دهد.

ابتدا نوع داده‌ها را بررسی می‌کند.

اگر نوع دو مقدار متفاوت باشد، نتیجه مستقیماً `false` خواهد بود.

مثال:

```javascript
5 === '5'
```

خروجی:

```text
false
```

زیرا:

```text
Number !== String
```

---

# چرا `===` بهتر است؟

فرض کنید کاربری سن خود را از طریق فرم وارد کرده است.

```javascript
const age = prompt();
```

مقدار برگشتی همیشه از نوع String است.

اگر بنویسیم:

```javascript
age == 18
```

نتیجه ممکن است:

```text
true
```

شود.

زیرا JavaScript رشته را به عدد تبدیل می‌کند.

اما اگر بنویسیم:

```javascript
age === 18
```

نتیجه:

```text
false
```

خواهد بود.

زیرا نوع داده‌ها متفاوت است.

به همین دلیل، استفاده از `===` رفتار برنامه را قابل پیش‌بینی‌تر می‌کند.

---

# عملگرهای نابرابری

دو عملگر دیگر نیز برای بررسی نابرابر بودن وجود دارند.

```javascript
!=
```

و

```javascript
!==
```

رفتار آن‌ها دقیقاً مشابه `==` و `===` است.

با این تفاوت که نتیجه را معکوس می‌کنند.

---

## مثال

```javascript
10 !== 5
```

خروجی:

```text
true
```

و

```javascript
10 !== 10
```

خروجی:

```text
false
```

# معرفی اولیه Type Coercion

در مثال قبل دیدیم که JavaScript گاهی نوع داده‌ها را به‌صورت خودکار تغییر می‌دهد.

این رفتار یکی از ویژگی‌های مهم JavaScript است که در فصل مستقلی با عنوان **Type Conversion and Type Coercion** به‌صورت کامل بررسی خواهد شد.

در این مرحله تنها کافی است بدانیم:

- `==` ممکن است تبدیل نوع انجام دهد.
- `===` هرگز این کار را انجام نمی‌دهد.

# نکات مهم

- خروجی تمام Comparison Operator ها از نوع Boolean است.
- عملگرهای `>`، `<`، `>=` و `<=` روابط عددی را بررسی می‌کنند.
- `==` ممکن است Type Coercion انجام دهد.
- `===` هم مقدار و هم نوع داده را مقایسه می‌کند.
- در پروژه‌های مدرن، `===` و `!==` انتخاب استاندارد هستند.
- درک صحیح Comparison Operatorها پایه اصلی ساختارهای تصمیم‌گیری مانند `if` و `switch` است که در فصل بعد با آن‌ها آشنا خواهیم شد.

# خلاصه فصل

در این فصل با یکی از مهم‌ترین اجزای هر زبان برنامه‌نویسی آشنا شدیم؛ **Operatorها**.

تا پیش از این، تنها می‌توانستیم داده‌ها را در متغیرها ذخیره کنیم، اما اکنون یاد گرفتیم که چگونه روی این داده‌ها عملیات مختلف انجام دهیم.

ابتدا با **Arithmetic Operatorها** آشنا شدیم و دیدیم که چگونه عملیات ریاضی روی داده‌ها انجام می‌شود.

سپس **Assignment Operatorها** را بررسی کردیم و متوجه شدیم که عملگر `=` در JavaScript به معنای «برابر بودن» نیست، بلکه برای اختصاص دادن یک مقدار به متغیر استفاده می‌شود.

در ادامه، **Comparison Operatorها** را شناختیم و یاد گرفتیم که این عملگرها همواره یک مقدار بولی (`true` یا `false`) تولید می‌کنند. همچنین تفاوت مهم میان `==` و `===` را بررسی کردیم و دلیل استفاده از مقایسه دقیق (`Strict Equality`) را در پروژه‌های حرفه‌ای فهمیدیم.

در نهایت، با مفهوم **Expression** و تفاوت آن با **Statement** آشنا شدیم؛ مفهومی که در فصل‌های آینده، به‌ویژه هنگام یادگیری شرط‌ها، توابع و JSX، نقش بسیار مهمی خواهد داشت.

# Key Takeaways

در پایان این فصل باید بتوانید نکات زیر را به‌طور کامل توضیح دهید:

- Operator عملی را روی یک یا چند Operand انجام می‌دهد.
- Operand داده یا متغیری است که عملگر روی آن اجرا می‌شود.
- Expression همیشه یک مقدار تولید می‌کند.
- Statement الزاماً مقدار تولید نمی‌کند.
- عملگرهای حسابی برای انجام محاسبات استفاده می‌شوند.
- عملگرهای Assignment مقدار جدیدی را در متغیر ذخیره می‌کنند.
- علامت `=` در JavaScript به معنای Assignment است، نه برابری.
- خروجی تمام Comparison Operatorها از نوع Boolean است.
- `===` علاوه بر مقدار، نوع داده را نیز بررسی می‌کند.
- در پروژه‌های مدرن، استفاده از `===` و `!==` بهترین انتخاب است.

# Golden Answers

## Operator چیست؟

Operator نماد یا کلمه‌ای است که عملی مشخص را روی یک یا چند Operand انجام می‌دهد و معمولاً نتیجه‌ای جدید تولید می‌کند.

---

## Operand چیست؟

Operand مقداری است که عملگر روی آن اجرا می‌شود.

---

## Expression چیست؟

هر قطعه کدی که در نهایت یک مقدار تولید کند، یک Expression است.

---

## Statement چیست؟

Statement دستوری است که عملی را در برنامه انجام می‌دهد و ممکن است مقدار تولید نکند.

---

## تفاوت Assignment و Comparison چیست؟

Assignment مقدار را داخل متغیر قرار می‌دهد.

Comparison دو مقدار را با هم مقایسه می‌کند.

---

## تفاوت `==` و `===`

`==`

- مقدارها را مقایسه می‌کند.
- ممکن است Type Coercion انجام دهد.

`===`

- هم مقدار و هم نوع داده را بررسی می‌کند.
- هیچ تبدیل خودکاری انجام نمی‌دهد.

---

## پاسخ کوتاه طلایی مصاحبه

**سؤال**

در پروژه‌های واقعی از `==` استفاده می‌کنید یا `===`؟

**پاسخ**

تقریباً همیشه از `===` استفاده می‌کنم، زیرا رفتار برنامه را قابل پیش‌بینی‌تر می‌کند و از تبدیل خودکار نوع داده‌ها جلوگیری می‌کند.
