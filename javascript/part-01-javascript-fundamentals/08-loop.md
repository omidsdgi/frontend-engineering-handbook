Chapter 08 — Loops
اهداف فصل
پس از پایان این فصل انتظار می‌رود بتوانید:
•	مفهوم Repetition را در برنامه‌نویسی توضیح دهید.
•	مفهوم Iteration را از تکرار ساده تشخیص دهید.
•	توضیح دهید چرا برنامه‌ها به Loop نیاز دارند.
•	تفاوت میان Loop و Conditional را درک کنید.
•	ساختار کلی یک Loop را توضیح دهید.
•	با ساختار پایه حلقه for در JavaScript آشنا شوید.
________________________________________
مقدمه
در فصل قبل دیدیم که JavaScript می‌تواند با استفاده از ساختارهای شرطی، مسیر اجرای برنامه را بر اساس شرایط مختلف تغییر دهد.اما تصمیم‌گیری تنها یکی ازنیازهای اصلی برنامه‌هاست. بسیاری از برنامه‌ها باید یک عملیات مشخص را چندین بار انجام دهند. برای مثال، یک فروشگاه اینترنتی ممکن است بخواهد:
اطلاعات چندین محصول را پردازش کند.			قیمت محصولات را بررسی کند.
سفارش‌های مختلف را محاسبه کند.			اطلاعات کاربران را بررسی کند.
داده‌های یک لیست را یکی‌یکی پردازش کند.
نوشتن یک دستور جداگانه برای هر مورد، معمولاً هم باعث تکرار کد می‌شود و هم نگهداری برنامه را دشوار می‌کند. اینجاست که مفهوم Loop اهمیت پیدا می‌کند.
________________________________________
چرا به Loop نیاز داریم؟
فرض کنید بخواهیم پنج محصول را بررسی کنیم. بدون Loop ممکن است مجبور شویم منطق یکسانی را چندین بار بنویسیم:	console.log('Product 1')	console.log('Product 2')	
این کد کار می‌کند، اما یک مشکل اساسی دارد. منطق برنامه تکرار شده است. اگر تعداد محصولات از پنج مورد به پنجاه یا پانصد مورد تغییر کند، این روش دیگر قابل استفاده نیست.
Loop به ما اجازه می‌دهد منطق انجام یک کار را یک بار تعریف کنیم و سپس اجرای آن را برای چندین مورد کنترل کنیم. برای مثال:						for (...) { console.log('Product') }
در این حالت، به‌جای نوشتن یک دستور برای هر محصول، ساختار Loop مسئول مدیریت تکرار خواهد بود. بنابراین هدف اصلی Loop فقط کوتاه‌تر کردن کد نیست. هدف مهم‌تر این است که:
منطق یک عملیات را از تعداد دفعات اجرای آن جدا کنیم.
این موضوع یکی از اصول مهم در طراحی کد قابل نگهداری است.
________________________________________
مفهوم Repetition
Repetition به معنای انجام یک عملیات به‌صورت تکراری است. در برنامه‌نویسی، ممکن است یک عملیات مشخص چندین بار لازم باشد. برای مثال، فرض کنید باید نام چند کاربر را نمایش دهیم:
عملیات اصلی در همه موارد یکسان است: 	نمایش نام کاربر		تنها داده تغییر می‌کند.
اگر تعداد کاربران کم باشد، ممکن است تکرار دستی قابل قبول به نظر برسد. اما در یک برنامه واقعی تعداد داده‌ها معمولاً ثابت نیست. ممکن است امروز 10 کاربر و فردا 10,000 کاربر داشته باشیم. به همین دلیل، برنامه باید بتواند عملیات یکسان را به‌صورت کنترل‌شده تکرار کند.
________________________________________
تعریف ساده
Repetition یعنی اجرای یک عملیات یا مجموعه‌ای از عملیات بیش از یک بار.
________________________________________
تعریف فنی
در برنامه‌نویسی، Repetition به اجرای مکرر یک بخش از منطق برنامه بر اساس یک قاعده یا شرط مشخص گفته می‌شود.
Loop یکی از مهم‌ترین ساختارهای زبان برای پیاده‌سازی این نوع تکرار است.
________________________________________
Iteration چیست؟
واژه Iteration در برنامه‌نویسی معمولاً به هر بار اجرای یک چرخه از یک Loop اشاره می‌کند. برای مثال، اگر یک Loop پنج بار اجرا شود، می‌توان گفت Loop دارای پنج Iteration بوده است. فرض کنید:
for (...) { console.log('Processing product') }
اگر این Loop پنج بار بدنه خود را اجرا کند، پنج Iteration خواهیم داشت. بنابراین باید میان دو مفهوم تفاوت قائل شویم:
•	Repetition به مفهوم کلی تکرار اشاره دارد.
•	Iteration به یک چرخه یا اجرای مشخص از آن تکرار اشاره می‌کند.
________________________________________
تعریف ساده
Iteration یعنی یک بار عبور Loop از چرخه اجرای خود.
تعریف فنی
Iteration یک اجرای مشخص از بدنه Loop در جریان فرایند تکرار است که مطابق شرایط و کنترل‌های تعریف‌شده برای آن Loop انجام می‌شود.
________________________________________
Loop چیست؟
Loop یک ساختار کنترلی در برنامه‌نویسی است که امکان اجرای مکرر یک بخش از کد را فراهم می‌کند.
در JavaScript چند نوع Loop وجود دارد که هرکدام برای شرایط خاصی مناسب هستند.
در این فصل با مهم‌ترین آن‌ها آشنا خواهیم شد:	for	while	do...while
همچنین یاد خواهیم گرفت چگونه اجرای Loop را با ابزارهایی مانند: break و continue کنترل کنیم.
________________________________________
تعریف ساده Loop
Loop ساختاری است که به برنامه اجازه می‌دهد یک بخش از کد را چندین بار اجرا کند.
________________________________________
تعریف فنی Loop
Loop یک Control Flow Statement است که اجرای مکرر یک Statement یا Block of Statements را بر اساس یک شرط یا سازوکار کنترل تکرار می‌کند.
________________________________________
Loop و Conditional چه تفاوتی دارند؟
در فصل قبل با Conditional آشنا شدیم. Conditional مشخص می‌کند که آیا یک بخش از کد باید اجرا شود یا خیر. برای مثال:					if (isLoggedIn) { console.log('Welcome')}
در اینجا شرط بررسی می‌شود و اگر نتیجه مناسب باشد، کد اجرا می‌شود.
اما Loop سؤال متفاوتی را پاسخ می‌دهد: 
در اینجا شرط بررسی می‌شود و اگر نتیجه مناسب باشد، کد اجرا می‌شود. 
اما Loop سؤال متفاوتی را پاسخ می‌دهد: این عملیات را چند بار باید انجام دهیم؟ بنابراین:
•	Conditional بیشتر برای تصمیم‌گیری استفاده می‌شود.
•	Loop برای تکرار اجرای منطق استفاده می‌شود.
این دو ساختار می‌توانند در کنار یکدیگر نیز استفاده شوند. برای مثال، یک برنامه ممکن است چندین محصول را بررسی کند و برای هر محصول نیز یک شرط را ارزیابی کند: 	for (...) { if (...) { // ... } }
در این حالت:
•	for مسئول تکرار است.
•	if مسئول تصمیم‌گیری است.
این تفاوت مفهومی درک صحیح Control Flow در JavaScript را ساده‌تر می‌کند.
________________________________________
ساختار کلی Loop
اگرچه انواع مختلف Loopها Syntax متفاوتی دارند، اما تقریباً همه آن‌ها یک ایده مشترک دارند:
شروع ↓  بررسی وضعیت تکرار ↓  اجرای عملیات ↓  حرکت به چرخه بعد ↓  بررسی دوباره ↓ ... ↓  پایان
بنابراین یک Loop معمولاً به سه سؤال اساسی پاسخ می‌دهد:
1.	از کجا شروع کنیم؟
2.	تا چه زمانی ادامه دهیم؟
3.	پس از هر Iteration چه تغییری ایجاد شود؟
در حلقه for این اجزا به‌صورت مشخص در Syntax آن قرار می‌گیرند.
________________________________________
معرفی حلقه for
یکی از رایج‌ترین روش‌های ایجاد Loop در JavaScript استفاده از for Statement است. ساختار پایه آن به شکل زیر است: در این ساختار، سه بخش اصلی وجود دارد:
 for (initialization; condition; update) { code }
و یک Block نیز وجود دارد که کدی را مشخص می‌کند که در هر Iteration اجرا خواهد شد. برای مثال:
for (let i = 0; i < 5; i++) {
  console.log('Processing product');
}
در این مثال، بخش 	console.log('Processing product')		بدنه Loop است.
اما سه بخش دیگر مسئول کنترل اجرای Loop هستند.
________________________________________
Loop Counter
در بسیاری از Loopها لازم است بدانیم در کدام Iteration قرار داریم. برای این کار معمولاً از یک متغیر به‌عنوان Loop Counter استفاده می‌کنیم. مثال:		for (let i = 0; i < 5; i++) {  console.log(i)}
یک متغیر به نام i ایجاد می‌کند که نقش Loop Counter را دارد. 
مقدار آن در هر Iteration تغییر می‌کند و به ما نشان می‌دهد Loop در چه مرحله‌ای قرار دارد.
________________________________________
تعریف ساده
Loop Counter متغیری است که برای شمارش یا کنترل Iterationهای یک Loop استفاده می‌شود.
________________________________________
تعریف فنی
Loop Counter معمولاً یک متغیر عددی است که مقدار آن در جریان اجرای Loop تغییر می‌کند و همراه با شرط Loop برای کنترل تعداد Iterationها به کار می‌رود.
________________________________________
Initialization
اولین بخش ساختار for، Initialization است.			 for (let i = 0; i < 5; i++) { // ... }
let i = 0 	بخش Initialization است. Initialization قبل از شروع اولین Iteration اجرا می‌شود.

یعنی ابتدا مقدار اولیه Loop Counter مشخص می‌شود:	i = 0	
سپس JavaScript به مرحله بررسی شرط می‌رود.
________________________________________
Condition
دومین بخش ساختار for، Condition است.	i < 5	شرط Loop است.
JavaScript قبل از هر Iteration این شرط را بررسی می‌کند. 
اگر نتیجه شرط:	true 	 باشد، بدنه Loop اجرا می‌شود.
اگر نتیجه شرط:	false	 باشد، Loop متوقف می‌شود.
بنابراین Condition مشخص می‌کند: آیا Loop باید یک Iteration دیگر اجرا شود یا خیر؟
________________________________________
Update
سومین بخش ساختار for، Update است. i++	بخش Update است. 
Update پس از اجرای بدنه Loop انجام می‌شود. در این مثال، مقدار i در هر Iteration یک واحد افزایش پیدا می‌کند. 0 → 1 → 2 → 3 → 4 → 5	وقتی مقدار i به 5 برسد: 
شرط 	i < 5	برابر با:		false	خواهد شد و Loop پایان می‌یابد.
________________________________________
ترتیب اجرای for
ترتیب کلی اجرای for چنین است:
Initialization ↓ Condition ↓ Body ↓ Update ↓ Condition ↓ Body ↓ Update ↓ ... ↓ Condition = false ↓ End
یک نکته مهم این است که Initialization فقط یک بار اجرا می‌شود. در مقابل:
•	Condition قبل از هر Iteration بررسی می‌شود.
•	Body در هر Iteration اجرا می‌شود.
•	Update پس از هر اجرای Body انجام می‌شود.
________________________________________
Trace کردن اجرای Loop
یکی از مهارت‌های مهم هنگام کار با Loop، توانایی Trace کردن اجرای آن است. 
Trace کردن یعنی اجرای Loop را مرحله‌به‌مرحله دنبال کنیم و مقدار متغیرها را در هر مرحله بررسی کنیم. 							 for (let i = 0; i < 4; i++) { console.log(i); }
________________________________________
الگوی متداول شمارش
یکی از رایج‌ترین کاربردهای for، اجرای یک عملیات برای تعداد مشخصی از دفعات است. مثال:
for (let i = 1; i <= 5; i++) { console.log(`Processing item ${i}`); }
________________________________________
پردازش داده‌ها
Loopها فقط برای چاپ اعداد یا شمارش استفاده نمی‌شوند. یکی از کاربردهای اصلی آن‌ها، پردازش چندین داده است. برای مثال، فرض کنید فهرستی از محصولات داریم:
const products = ['Laptop', 'Phone', 'Monitor']   می‌توانیم با for هر محصول را یکی‌یکی پردازش کنیم:
for (let i = 0; i < products. length; i++) {  console.log(products[i])}
در این مثال، Loop Counter نقش مهمی دارد. در هر Iteration مقدار i مشخص می‌کند که کدام عنصر از مجموعه باید پردازش شود.		 i = 0 → products[0] i = 1 → products[1] i = 2 → products[2]
این یکی از الگوهای بسیار رایج استفاده از for در برنامه‌های واقعی است.
________________________________________
چرا Condition معمولاً با length ترکیب می‌شود؟

هنگامی که با یک مجموعه از داده‌ها کار می‌کنیم، معمولاً تعداد عناصر از قبل مشخص نیست.
برای مثال: const products = ['Laptop', 'Phone', 'Monitor']	تعداد عناصر این مجموعه برابر با: products. length است. بنابراین به‌جای نوشتن یک عدد ثابت، بهتر است از اندازه واقعی مجموعه استفاده کنیم. مزیت این روش این است که اگر تعداد محصولات تغییر کند، شرط Loop نیز همچنان صحیح باقی می‌ماند و نیازی به تغییر Loop نداریم. Loop خودش تعداد عناصر موجود را در زمان اجرا بررسی می‌کند.

❌ تصور اینکه Update قبل از اجرای Body انجام می‌شود.

•	Loop Counter معمولاً برای کنترل Iterationها استفاده می‌شود.
•	Initialization قبل از شروع Loop اجرا می‌شود.
•	Condition قبل از هر Iteration بررسی می‌شود.
•	اگر Condition برابر true باشد، Body اجرا می‌شود.
•	Update پس از اجرای Body انجام می‌شود.
•	اگر Condition برابر false شود، Loop پایان می‌یابد.
•	الگوی i < array. length برای پردازش عناصر یک مجموعه بسیار رایج است.
•	Trace کردن Loop به درک دقیق ترتیب اجرای آن کمک می‌کند.

while, do...while and Nested Loops
تا اینجا دیدیم که حلقه for چگونه با استفاده از Initialization، Condition و Update تعداد Iterationها را کنترل می‌کند. اما همیشه از قبل نمی‌دانیم که یک عملیات دقیقاً چند بار باید اجرا شود. گاهی تنها چیزی که می‌دانیم این است که:
تا زمانی که یک شرط برقرار است، اجرای کد باید ادامه پیدا کند.
برای چنین شرایطی، JavaScript حلقه‌های دیگری مانند while و do...while را نیز در اختیار ما قرار می‌دهد.
________________________________________
حلقه while
حلقه while زمانی استفاده می‌شود که ادامه تکرار به یک Condition وابسته باشد. 
ساختار کلی آن:								while (condition) { // code }
در این ساختار، برخلاف for، Initialization و Update بخشی از Syntax خود Loop نیستند. مثال:
let i = 0;    while (i < 5) { console.log(i); i++; }	
در این مثال:	i < 5	شرط ادامه Loop است.
تا زمانی که این شرط true باشد، بدنه Loop اجرا می‌شود.
________________________________________
تعریف ساده
while یک Loop است که تا زمانی که یک شرط true باشد، بدنه خود را اجرا می‌کند.
________________________________________
تعریف فنی
while یک Iteration Statement است که پیش از هر Iteration، Expression شرطی را ارزیابی می‌کند و تنها در صورت true بودن آن، Statement یا Block مربوطه را اجرا می‌کند.
به همین دلیل، while یک Pre-test Loop محسوب می‌شود.
________________________________________
ترتیب اجرای while
Condition ↓ true ↓ Body ↓ Update ↓ Condition ↓ true ↓ Body ↓ Update ↓ Condition ↓ false ↓ End
نکته مهم این است که Condition قبل از اجرای Body بررسی می‌شود. 
بنابراین اگر شرط از ابتدا false باشد، Body حتی یک بار نیز اجرا نخواهد شد.
		 let i = 10;   while (i < 5) { console.log(i)} 
در اینجا: i < 5 از ابتدا false است. بنابراین هیچ خروجی تولید نمی‌شود.
________________________________________
while و Loop Counter
در بسیاری از مثال‌های while نیز از یک Counter استفاده می‌کنیم:
let i = 0; while (i < 5) { 
console.log(i);
i++; }
اما تفاوت مهم این است که برخلاف for، Counter در بخش جداگانه‌ای از Syntax Loop قرار ندارد.
ما خودمان مسئول تغییر مقدار آن هستیم: 	i++	به همین دلیل هنگام استفاده از while باید مراقب باشیم که وضعیت مربوط به Loop به‌درستی تغییر کند.
________________________________________
Infinite Loop
یکی از اشتباهات رایج در while این است که شرط هیچ‌گاه false نشود. برای مثال:
let i = 0; while (i < 5) {  console.log(i)}
در اینجا مقدار i هیچ‌گاه تغییر نمی‌کند و همیشه true باقی می‌ماند. در نتیجه Loop متوقف نمی‌شود.
به چنین حالتی Infinite Loop گفته می‌شود. اگر Loop به تغییر یک Counter یا وضعیت دیگر وابسته است، باید اطمینان داشته باشیم که این تغییر واقعاً اتفاق می‌افتد.
________________________________________
حلقه do...while
حلقه do...while شبیه while است، اما یک تفاوت مهم دارد. در while ابتدا شرط بررسی می‌شود:
while (condition) { // code }  اما در do...while ابتدا Body اجرا می‌شود و سپس شرط بررسی می‌شود:
do {  // code} while (condition)
________________________________________
تعریف ساده
do...while حلقه‌ای است که Body آن حداقل یک بار اجرا می‌شود و سپس شرط برای ادامه Loop بررسی می‌شود.
________________________________________
تعریف فنی
do...while یک Iteration Statement است که ابتدا Statement مربوط به Body را اجرا می‌کند و سپس Condition را ارزیابی می‌کند. به همین دلیل یک Post-test Loop محسوب می‌شود.
________________________________________
تفاوت while و do...while
تفاوت اصلی در زمان بررسی Condition است. 
در while:		 Condition ↓ Body
در do...while:	Body ↓ Condition
این تفاوت باعث می‌شود do...while حتی اگر شرط از ابتدا false باشد، یک بار اجرا شود.
let i = 10;
 do {  
console.log(i)
} while (i < 5);
خروجی: 10 است. چرا؟ 
زیرا Body قبل از بررسی شرط اجرا شده است.
________________________________________
چه زمانی از while استفاده کنیم؟
while زمانی مناسب است که تعداد Iterationها از قبل مشخص نباشد و ادامه Loop به یک شرط وابسته باشد. با این حال، اگر مسئله ذاتاً یک شمارش مشخص باشد، for معمولاً ساختار واضح‌تری ارائه می‌دهد.
________________________________________
تفاوت for و while
از نظر قدرت، هر دو می‌توانند بسیاری از مسائل مشابه را حل کنند. تفاوت اصلی در نحوه بیان منطق Loop است. 
در for، اجزای اصلی شمارش در یک ساختار فشرده قرار گرفته‌اند: for (initialization; condition; update)
در while، این اجزا معمولاً در نقاط مختلف کد قرار می‌گیرند. بنابراین می‌توان به‌صورت عملی گفت:
•	for برای Iterationهایی که ساختار شمارش مشخصی دارند، بسیار مناسب است.
•	while برای Iterationهایی که ادامه آن‌ها بیشتر به یک Condition وابسته است، خوانایی خوبی دارد.
________________________________________
Nested Loops
گاهی لازم است یک Loop درون Loop دیگری قرار گیرد. به این ساختار Nested Loop گفته می‌شود.
for (let i = 0; i < 3; i++) {
 for (let j = 0; j < 2; j++) {
 console.log(i, j); } }
در اینجا یک for داخل for دیگری قرار گرفته است.
________________________________________
تعریف ساده
Nested Loop یعنی قرار گرفتن یک Loop درون Loop دیگر.
________________________________________
تعریف فنی
Nested Loop ساختاری است که در آن یک Iteration Statement درون Body یک Iteration Statement دیگر قرار می‌گیرد. در هر Iteration از Loop بیرونی، Loop داخلی می‌تواند به‌طور کامل اجرا شود.
________________________________________
کاربرد Nested Loops
Nested Loop زمانی کاربرد دارد که داده‌ها دارای ساختار چندسطحی باشند. برای مثال، تصور کنید یک سیستم فروشگاهی چند سفارش دارد و هر سفارش چند محصول دارد. در چنین مسئله‌ای می‌توان از یک Loop برای پیمایش سفارش‌ها و از Loop دیگری برای پردازش محصولات هر سفارش استفاده کرد.
for (const order of orders) {
  for (const product of order. products) {
    // process product
  }}
این مثال نشان می‌دهد Nested Loop فقط یک تکنیک سینتکسی نیست؛ بلکه برای پردازش داده‌های چندسطحی در برنامه‌های واقعی کاربرد دارد.
________________________________________
نکته مهم درباره Nested Loops
هر بار که Loop بیرونی یک Iteration انجام می‌دهد، Loop داخلی نیز اجرای خود را از ابتدا شروع می‌کند. به همین دلیل تعداد اجرای Body در Nested Loop می‌تواند به‌سرعت افزایش پیدا کند.
بنابراین Nested Loop باید با توجه به اندازه داده‌ها و هزینه عملیات داخلی با دقت استفاده شود.

Controlling Loop Execution
گاهی اما مسئله فقط این نیست که Loop چند بار اجرا شود. ممکن است در میانه اجرای Loop بخواهیم:
•	اجرای Loop را کاملاً متوقف کنیم.
•	اجرای Iteration فعلی را نادیده بگیریم و به Iteration بعد برویم.
JavaScript برای این دو نیاز، دو Statement مهم در اختیار ما قرار می‌دهد: break	continue
________________________________________
break
break برای خروج فوری از Loop استفاده می‌شود. هنگامی که JavaScript به break می‌رسد، اجرای Loop متوقف می‌شود و برنامه از اولین Statement بعد از Loop ادامه پیدا می‌کند. مثال:
for (let i = 0; i < 10; i++) {
  if (i === 5) { 
   break  }
  console.log(i)}
وقتی مقدار i به 5 می‌رسد، break اجرا می‌شود و Loop بلافاصله پایان پیدا می‌کند.
________________________________________
تعریف ساده
break اجرای Loop را بلافاصله متوقف می‌کند.
________________________________________
تعریف فنی
break یک Jump Statement است که اجرای نزدیک‌ترین Loop را متوقف کرده و کنترل برنامه را به Statement بعد از آن ساختار منتقل می‌کند.  
نکته مهم این است که break باعث نمی‌شود فقط Iteration فعلی پایان پیدا کند. بلکه کل Loop را متوقف می‌کند.
________________________________________
استفاده عملی از break
یکی از کاربردهای رایج break زمانی است که به نتیجه موردنظر خود رسیده‌ایم و دیگر نیازی به ادامه پردازش نداریم. برای مثال:					      const numbers = [4, 8, 15, 16, 23, 42]
 for (let i = 0; i < numbers. length; i++) { 
if (numbers[i] === 23) { 
console.log('Number found')
break} }
در این مثال، پس از پیدا شدن 23 دیگر نیازی به ادامه جست‌وجو نداریم. 
بنابراین break از اجرای Iterationهای غیرضروری جلوگیری می‌کند.
________________________________________
continue
برخلاف break، Statement مربوط به continue کل Loop را متوقف نمی‌کند. continue باعث می‌شود اجرای Iteration فعلی متوقف شود و Loop به Iteration بعدی برود. مثال:
for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue  }
  console.log(i) }
خروجی: 0 1 3 4
________________________________________
تعریف ساده
continue اجرای Iteration فعلی را متوقف می‌کند و Loop را به Iteration بعدی می‌برد.
________________________________________
تعریف فنی
continue یک Jump Statement است که ادامه اجرای Iteration فعلی را متوقف کرده و کنترل را به مرحله بعدی چرخه Loop منتقل می‌کند.
________________________________________
تفاوت break و continue
تفاوت این دو Statement بسیار مهم است.
Statement				رفتار
break				کل Loop را متوقف می‌کند
continue			فقط Iteration فعلی را متوقف می‌کند
continue در پردازش داده‌ها
یکی از کاربردهای رایج continue زمانی است که برخی داده‌ها نباید پردازش شوند. برای مثال:
const numbers = [1, -2, 3, -4, 5];
 for (let i = 0; i < numbers. length; i++) {
 if (numbers[i] < 0) {
 continue  }
 console.log(numbers[i])  }
در این مثال، اعداد منفی از پردازش خارج می‌شوند. اما Loop همچنان برای عناصر بعدی ادامه پیدا می‌کند.
________________________________________
break و continue همراه با شرط
هر دو Statement معمولاً همراه با Conditional استفاده می‌شوند. برای مثال:
for (let i = 0; i < 10; i++) {
 if (i === 7) {
 break; }
 if (i % 2 === 0) {
 continue  }
 console.log(i)  }
بنابراین Loop و Conditional می‌توانند برای ایجاد منطق کنترل پیچیده‌تر در کنار یکدیگر استفاده شوند.
________________________________________
break در while
break فقط مخصوص for نیست. می‌توان از آن در while نیز استفاده کرد.		      let i = 0
while (i < 10) {
 if (i === 5) {
 break }
 console.log(i);
 i++ }
رفتار break مستقل از نوع Loop است. هر زمان اجرا شود، نزدیک‌ترین Loop را متوقف می‌کند.
________________________________________
continue در while
continue نیز در while قابل استفاده است.							let i = 0
 while (i < 5) {
 i++;
 if (i === 3) { 
continue }
 console.log(i) }
در اینجا مقدار 3 نادیده گرفته می‌شود، اما Loop ادامه پیدا می‌کند.
________________________________________
نکته مهم در while
هنگام استفاده از continue در while باید مراقب Update باشیم. برای مثال، این کد مشکل دارد:
let i = 0;
while (i < 5) {
  if (i === 3) {
    continue  }
  i++ }
وقتی i به 3 برسد، continue اجرا می‌شود و دستور i++ دیگر اجرا نمی‌شود. در نتیجه i همچنان برابر 3 باقی می‌ماند و شرط: i < 5  همیشه true خواهد بود. این وضعیت می‌تواند باعث Infinite Loop شود.

به همین دلیل، هنگام استفاده از continue درwhile باید مسیر تغییر وضعیت Loop را با دقت بررسی کنیم.
________________________________________
Nested Loops و break
در Nested Loop، break به‌صورت پیش‌فرض فقط نزدیک‌ترین Loop را متوقف می‌کند. مثال:
for (let i = 0; i < 3; i++) {
 for (let j = 0; j < 3; j++) {
 if (j === 1) {
 break } 
console.log(i, j) } }
در اینجا break مربوط به Loop داخلی است. بنابراین وقتی: j === 1 شود، فقط Loop داخلی متوقف می‌شود. Loop بیرونی همچنان ادامه پیدا می‌کند.
________________________________________
continue در Nested Loops
رفتار continue نیز به نزدیک‌ترین Loop مربوط می‌شود.
for (let i = 0; i < 2; i++) {
 for (let j = 0; j < 3; j++) {
 if (j === 1) {
 continue } 
console.log(i, j)  } }
در این مثال، continue فقط Iteration مربوط به Loop داخلی را رد می‌کند. خروجی:
0 0 ,0 2, 1 0 , 1 2  
________________________________________
آیا باید همیشه از break و continue استفاده کنیم؟
خیر. این Statementها ابزارهای مفیدی هستند، اما استفاده بیش از حد از آن‌ها می‌تواند جریان اجرای Loop را پیچیده کند. مثلاً اگر بتوانیم منطق Loop را با یک Condition ساده و خوانا بیان کنیم، معمولاً بهتر است به جای چندین break و continue از همان ساختار شرطی استفاده کنیم.
هدف اصلی همیشه باید این باشد:
•	منطق Loop برای برنامه‌نویس بعدی قابل درک باشد.
•	بنابراین استفاده از break یا continue زمانی مناسب است که واقعاً باعث ساده‌تر شدن منطق شود.

❌ اشتباه اول: فراموش کردن Update								i++

❌ اشتباه دوم: استفاده نادرست از شرط Loop
شرط باید دقیقاً مشخص کند که Loop تا چه زمانی باید ادامه پیدا کند.		 i < users. length

گاهی Loop تقریباً درست کار می‌کند، اما یک Iteration بیشتر یا کمتر از مقدار مورد انتظار اجرا می‌شود. به این نوع خطا Off-by-One Error گفته می‌شود.					while (i < 5) {
❌ اشتباه چهارم: تغییر ندادن Counter در جای مناسب		if (i === 2) { continue }       
در while، برنامه‌نویس مسئول تغییر وضعیت Loop است.					   	 i++;
❌  اشتباه پنجم: استفاده بیش از حد از Nested Loops
Nested Loop ابزار قدرتمندی است، اما هر Loop داخلی برای هر Iteration از Loop بیرونی اجرا می‌شود.
بنابراین اگر Loop داخلی عملیات سنگینی انجام دهد، تعداد زیاد Iterationها می‌تواند روی عملکرد برنامه تأثیر بگذارد.
❌ اشتباه ششم: استفاده از Loop برای مسئله‌ای که به Loop نیاز ندارد
هر تکراری الزاماً به معنای استفاده از Loop نیست. مثلاً اگر فقط بخواهیم یک عملیات مشخص را یک بار انجام دهیم، استفاده از Loop منطقی نیست.
❌ اشتباه هفتم: استفاده افراطی از break و continue
break و continue ابزارهای مفیدی هستند، اما استفاده بیش از حد از آن‌ها می‌تواند جریان اجرای Loop را دشوار کند. با افزایش تعداد شرط‌ها، دنبال کردن مسیر اجرای Loop دشوارتر می‌شود. بنابراین باید از این Statementها با هدف مشخص استفاده کنیم.
اصل مهم: کوتاه‌تر بودن کد همیشه به معنای خواناتر بودن آن نیست.
❌ اشتباه هشتم: انتخاب Loop بر اساس عادت
گاهی برنامه‌نویس همیشه از for استفاده می‌کند، حتی زمانی که ساختار مسئله با while واضح‌تر بیان می‌شود. یا برعکس، همیشه از while استفاده می‌کند. انتخاب Loop نباید بر اساس عادت باشد.
بهتر است ابتدا مسئله را بررسی کنیم:
•	آیا تعداد Iterationها ساختار شمارشی مشخصی دارد؟
•	آیا ادامه Loop به یک Condition وابسته است؟
•	آیا Body باید حداقل یک بار اجرا شود؟
•	آیا داده‌ها دارای ساختار چندسطحی هستند؟
سپس مناسب‌ترین ساختار را انتخاب کنیم.

Best Practice
یک Loop خوب باید سه ویژگی اصلی داشته باشد:
1. قابل فهم باشد : خواننده باید بتواند به‌سرعت بفهمد Loop چه کاری انجام می‌دهد.
2. پایان آن مشخص باشد: باید مشخص باشد Loop تحت چه شرایطی متوقف می‌شود.
3. وضعیت آن به‌درستی تغییر کند. اگر ادامه Loop به یک Counter یا وضعیت مشخص وابسته است، آن وضعیت باید در مسیر صحیح تغییر کند. به‌خصوص در while این موضوع اهمیت زیادی دارد.

در این فصل با مفهوم Repetition و Iteration شروع کردیم و دیدیم که برنامه‌ها برای پردازش مکرر داده‌ها و اجرای چندباره یک منطق به Loop نیاز دارند. 
سپس با ساختار for آشنا شدیم و سه بخش اصلی آن را بررسی کردیم: Initialization, Condition, Update
دیدیم که Loop Counter معمولاً برای کنترل تعداد Iterationها استفاده می‌شود و الگوی زیر یکی از رایج‌ترین روش‌ها برای پیمایش مجموعه‌ای از داده‌هاست: for (let i = 0; i < items. length; i++) { // ... }
در ادامه با while آشنا شدیم و دیدیم که این Loop تا زمانی ادامه پیدا می‌کند که Condition برابر true باشد. سپس do...while را بررسی کردیم و تفاوت مهم آن با while را شناختیم:
while → Condition → Body    					 do...while → Body → Condition
بنابراین do...while می‌تواند Body را حداقل یک بار اجرا کند.
بعد از آن Nested Loops را بررسی کردیم و دیدیم که یک Loop می‌تواند درون Loop دیگری قرار گیرد.
در نهایت با دو ابزار مهم کنترل Loop آشنا شدیم: break برای خروج از Loop و
 continue برای رد کردن Iteration فعلی.

Key Takeaways
•	Repetition به معنای اجرای مکرر یک عملیات است.
•	Iteration به یک چرخه مشخص از اجرای Loop اشاره می‌کند.
•	Loop یکی از ساختارهای اصلی Control Flow در JavaScript است.
•	for برای Iterationهای دارای ساختار شمارشی مشخص بسیار مناسب است.
•	while تا زمانی اجرا می‌شود که Condition برابر true باشد.
•	do...while ابتدا Body را اجرا می‌کند و سپس Condition را بررسی می‌کند.
•	do...while حداقل یک بار اجرا می‌شود.
•	Nested Loop یک Loop درون Loop دیگر است.
•	break کل نزدیک‌ترین Loop را متوقف می‌کند.
•	continue فقط Iteration فعلی را رد می‌کند.
•	در while باید به تغییر وضعیت Loop توجه ویژه داشت.
•	Off-by-One Error یکی از خطاهای رایج هنگام تعیین محدوده Loop است.
•	انتخاب Loop باید بر اساس منطق مسئله انجام شود، نه عادت برنامه‌نویس.
•	Loop باید خوانا، قابل کنترل و دارای شرایط پایان مشخص باشد.

Technical Interview
سطح پایه (Junior)
⭐  Loop چیست؟
Loop یک Control Flow Statement است که امکان اجرای مکرر یک بخش از کد را بر اساس یک شرط یا سازوکار کنترل تکرار فراهم می‌کند.
⭐  تفاوت Repetition و Iteration چیست؟
Repetition به معنای تکرار یک عمل یا مجموعه‌ای از دستورات است، در حالی که Iteration به هر بار اجرای یک چرخه از یک ساختار تکرار گفته می‌شود.
به‌عبارت دقیق‌تر، Iteration واحدِ اجرای یک Loop است؛ یک Loop می‌تواند شامل چندین Iteration باشد، در حالی که Repetition مفهوم کلی‌تری برای تکرار است.
⭐  تفاوت for و while چیست؟
for معمولاً زمانی مناسب است که ساختار Iteration شامل Initialization، Condition و Update مشخصی باشد؛ درحالی که while زمانی خوانایی بیشتری دارد که ادامه Loop عمدتاً به یک Condition وابسته باشد
⭐  break چیست؟
break اجرای نزدیک‌ترینLoop را متوقف می‌کند وکنترل برنامه را به Statement بعدازLoop منتقل می‌کند
⭐  continue چیست؟
continue اجرای Iteration فعلی را متوقف می‌کند و باعث می‌شود Loop به Iteration بعدی منتقل شود.
⭐  Infinite Loop چیست؟
Infinite Loop حلقه‌ای است که شرط پایان آن هیچ‌گاه false نمی‌شود و در نتیجه Loop متوقف نمی‌شود.
⭐  Nested Loop چیست؟
Nested Loop ساختاری است که در آن یک Loop درون Loop دیگری قرار گرفته است. در این حالت Loop داخلی می‌تواند برای هر Iteration از Loop بیرونی اجرا شود.
⭐  سه بخش اصلی حلقه for چیست؟
Initialization، 	Condition 	 Update	
⭐  Loop Counter چه کاربردی دارد؟
Loop Counter متغیری است که تعداد دفعات اجرای Loop را ردگیری و کنترل می‌کند.
کاربردهای اصلی آن:
•	تعیین نقطه شروع و پایان Loop
•	تغییر وضعیت Loop در هر Iteration
•	مشخص‌کردن تعداد دفعات تکرار
•	استفاده از شماره Iteration در منطق برنامه
در for معمولاً همان متغیر بخش اول حلقه نقش Loop Counter را دارد.
⭐  تفاوت while و do...while چیست؟
در while ابتدا Condition بررسی می‌شود و سپس Body اجرا می‌شود؛ اما در do...while ابتدا Body اجرا شده و سپس Condition بررسی می‌شود. بنابراین do...while حداقل یک بار اجرا می‌شود.
⭐  break چه کاری انجام می‌دهد؟
break اجرای Loop یا switch را بلافاصله متوقف می‌کند و کنترل برنامه را به اولین دستور بعد از آن ساختار منتقل می‌کند. در Loop، break باعث می‌شود Iterationهای باقی‌مانده اجرا نشوند و حلقه زودتر از شرط پایان طبیعی خود خاتمه پیدا کند.
⭐  continue چه کاری انجام می‌دهد؟
continue اجرای Iteration فعلی را متوقف می‌کند و کنترل را به Iteration بعدی Loop منتقل می‌کند، بدون اینکه کل Loop خاتمه پیدا کند.
سطح متوسط (Mid-Level)
⭐  چرا در پیمایش یک آرایه معمولاً از شرط i < array. length استفاده می‌کنیم؟

⭐  Infinite Loop چیست و چگونه ایجاد می‌شود؟
Infinite Loop حلقه‌ای است که شرط پایان آن هیچ‌گاه برقرار نمی‌شود و در نتیجه اجرای Loop بدون توقف ادامه پیدا می‌کند. معمولاً زمانی ایجاد می‌شود که شرط Loop همیشه true باقی بماند یا متغیر کنترل‌کننده Loop به‌درستی تغییر نکند.
⭐  Off-by-One Error چیست؟
خطای منطقی‌ای است که در آن یک Loop یا محاسبه، یک بار بیشتر یا یک بار کمتر از مقدار موردنظر اجرا یا محاسبه می‌شود؛ معمولاً به دلیل تعیین نادرست شرط شروع، پایان یا محدوده Iteration. مثلاً انتخاب نادرست عملگرهای	 < و <= 	یا 	> و >=
⭐  چه زمانی for را به while ترجیح می‌دهید؟
for را زمانی ترجیح می‌دهم که تعداد Iterationها یا منطق کنترل Loop از ابتدا مشخص و متمرکز باشد؛ while را زمانی انتخاب می‌کنم که تعداد تکرارها از قبل مشخص نیست و ادامه Loop به یک شرط وابسته است.
⭐  Nested Loop چگونه اجرا می‌شود؟
Nested Loop به این صورت اجرا می‌شود که در هر Iteration حلقه بیرونی، حلقه داخلی از ابتدا تا پایان خود به‌طور کامل اجرا می‌شود؛ سپس حلقه بیرونی به Iteration بعدی می‌رود و این روند تکرار می‌شود. در نتیجه اگر حلقه بیرونی n بار و حلقه داخلی m بار اجرا شود، بدنه حلقه داخلی در مجموع n × m بار اجرا خواهد شد.
⭐  چرا استفاده نادرست از continue در while می‌تواند باعث Infinite Loop شود؟
زیرا در while معمولاً تغییر Loop Counter یا وضعیت شرط در بدنه حلقه انجام می‌شود؛ اگر continue قبل از این تغییر اجرا شود، کنترل مستقیماً به بررسی شرط برمی‌گردد، در حالی که وضعیت شرط تغییر نکرده است و حلقه می‌تواند برای همیشه ادامه پیدا کند.
سطح پیشرفته (Senior)
⭐  در چه شرایطی استفاده از Nested Loop می‌تواند مشکل عملکردی ایجاد کند؟
استفاده از Nested Loop زمانی می‌تواند مشکل عملکردی ایجاد کند که تعداد Iterationهای حلقه‌های تو‌در‌تو زیاد باشد؛ زیرا تعداد اجرای عملیات معمولاً به‌صورت ضربی افزایش می‌یابد.
در نتیجه، اگر حلقه‌های داخلی روی داده‌های بزرگ اجرا شوند، باعث افزایش قابل‌توجه زمان اجرا شود.
⭐  چگونه می‌توان خوانایی یک Loop پیچیده را افزایش داد؟
با نام‌گذاری معنادار متغیرها، ساده‌سازی شرط‌ها، شکستن منطق پیچیده به توابع کوچک، کاهش تو‌در‌تویی، و قرار دادن مراحل مرتبط در ساختار مشخص می‌توان خوانایی یک Loop پیچیده را افزایش داد.
همچنین باید از استفاده غیرضروری از break و continue پرهیز کرد و در صورت امکان، منطق Loop را به چند مرحله ساده‌تر تقسیم کرد.
⭐  آیا کوتاه‌تر بودن یک Loop الزاماً به معنای بهتر بودن آن است؟
خیر. کوتاه‌تر بودن Loop الزاماً به معنای بهتر بودن آن نیست؛ خوانایی، وضوح منطق، قابلیت نگهداری و صحت رفتار معیارهای مهم‌تری هستند. کدی که کمی طولانی‌تر اما واضح‌تر باشد، معمولاً انتخاب بهتری است.

جمع‌بندی فصل
Loop یکی از پایه‌ای‌ترین ابزارهای کنترل جریان در JavaScript است. برنامه‌های واقعی دائماً با داده‌هایی مواجه می‌شوند که تعداد آن‌ها از قبل مشخص نیست یا نیاز دارند یک عملیات مشابه برای چندین مورد انجام شود.
در چنین شرایطی، به جای تکرار دستی کد، منطق موردنظر را در یک Loop قرار می‌دهیم و تعداد یا شرایط اجرای آن را کنترل می‌کنیم.
در این فصل یاد گرفتیم که:
For برای Loopهای دارای ساختار شمارشی مناسب است؛
While برای تکراری مناسب است که ادامه آن به یک Condition وابسته است؛
do...while	زمانی مفید است که Body باید حداقل یک بار اجرا شود.
همچنین یاد گرفتیم که break و continue امکان کنترل دقیق‌تر اجرای Loop را فراهم می‌کنند.

Conclusion
Loopها فقط ابزاری برای تکرار چند خط کد نیستند؛ بلکه یکی از پایه‌های اصلی Control Flow در برنامه‌نویسی محسوب می‌شوند. با درک صحیح for، while، do...while، Nested Loops، break و continue می‌توانیم منطق تکراری برنامه را به‌شکل کنترل‌شده و قابل نگهداری بیان کنیم.
