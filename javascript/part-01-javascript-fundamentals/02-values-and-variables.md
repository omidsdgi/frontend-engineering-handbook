# Chapter 02

# Values and Variables

---

# اهداف این فصل

پس از مطالعه این فصل، انتظار می‌رود بتوانید:

- مفهوم Value را توضیح دهید.
- مفهوم Variable را تعریف کنید.
- تفاوت Value و Variable را بیان کنید.
- علت استفاده از متغیرها را توضیح دهید.
- قواعد نام‌گذاری متغیرها را بشناسید.
- مفهوم Assignment را درک کنید.
- تفاوت Declare، Initialize و Assign را توضیح دهید.

---

# مقدمه

تقریباً هر برنامه‌ای که نوشته می‌شود، با داده‌ها سروکار دارد.

یک برنامه ممکن است نام کاربر را ذخیره کند، قیمت یک محصول را محاسبه کند، نتیجه یک آزمون را نمایش دهد یا وضعیت ورود کاربر را بررسی کند.

تمام این اطلاعات، در نهایت به دو مفهوم پایه وابسته هستند:

- Value
- Variable

درک صحیح این دو مفهوم، پایه بسیاری از مباحث بعدی JavaScript است.

---

# Value چیست؟

**Value** به هر داده‌ای گفته می‌شود که JavaScript بتواند آن را بشناسد و روی آن عملیاتی انجام دهد.

برای مثال:

```javascript
10

25.8

"Hello"

true

false

null
```

همه این‌ها Value هستند.

به بیان ساده:

> Value همان داده‌ای است که برنامه با آن کار می‌کند.

---

# Variable چیست؟

اگر قرار بود همیشه مقادیر را مستقیماً داخل کد بنویسیم، برنامه‌های ما تقریباً غیرقابل مدیریت می‌شدند.

به همین دلیل از Variable استفاده می‌کنیم.

**Variable** محلی نام‌گذاری‌شده برای نگهداری یک مقدار است.

به جای اینکه مقدار را هر بار مستقیماً بنویسیم، آن را داخل یک متغیر قرار می‌دهیم و از نام متغیر استفاده می‌کنیم.

---

# یک مثال ساده

```javascript
const firstName = "Omid";
```

در این مثال:

- `firstName` نام متغیر است.
- `"Omid"` مقدار ذخیره‌شده است.

---

# چرا از Variable استفاده می‌کنیم؟

فرض کنید قیمت یک محصول در چندین بخش برنامه استفاده شده است.

اگر مقدار را مستقیماً در همه جا بنویسیم:

```javascript
120
```

در صورت تغییر قیمت باید تمام قسمت‌های برنامه را پیدا کرده و ویرایش کنیم.

اما اگر مقدار داخل یک متغیر قرار گیرد:

```javascript
const price = 120;
```

تنها کافی است همان متغیر را تغییر دهیم.

استفاده از متغیرها باعث می‌شود کد:

- خواناتر باشد.
- نگهداری آسان‌تری داشته باشد.
- احتمال خطا کاهش پیدا کند.

---

# Variable مانند یک برچسب است

بسیاری از افراد تصور می‌کنند متغیر همان مقدار است.

در واقع متغیر فقط یک **نام** برای دسترسی به یک مقدار است.

برای مثال:

```javascript
const age = 25;
```

در این مثال:

- مقدار برابر 25 است.
- متغیر فقط نامی است که برای دسترسی به آن انتخاب کرده‌ایم.

---

# اعلان متغیر (Declaration)

قبل از استفاده از یک متغیر، باید آن را معرفی کنیم.

به این عمل **Declaration** گفته می‌شود.

```javascript
let score;
```

در این مرحله فقط متغیر ایجاد شده است و هنوز مقداری ندارد.

---

# مقداردهی اولیه (Initialization)

اگر هنگام ایجاد متغیر، مقداری نیز به آن اختصاص دهیم، این عمل را Initialization می‌گویند.

```javascript
let score = 100;
```

---

# انتساب مقدار (Assignment)

بعداً نیز می‌توان مقدار جدیدی به متغیر اختصاص داد.

```javascript
let score = 100;

score = 150;
```

در این مثال:

ابتدا مقدار 100 ذخیره شده است.

سپس مقدار جدید جایگزین مقدار قبلی می‌شود.

---

# تفاوت Declaration و Assignment

کد زیر را مشاهده کنید.

```javascript
let city;

city = "Berlin";
```

خط اول:

Declaration

خط دوم:

Assignment

---

# قوانین نام‌گذاری متغیرها

نام متغیر باید معنی‌دار باشد.

مثال‌های مناسب:

```javascript
firstName

totalPrice

userAge

courseName
```

---

نام‌های نامناسب:

```javascript
a

x

abc

temp1
```

مگر اینکه در مثال‌های بسیار کوچک استفاده شوند.

---

# قوانین نحوی

نام متغیر:

- می‌تواند شامل حروف باشد.
- می‌تواند شامل اعداد باشد.
- می‌تواند شامل `_` باشد.
- می‌تواند شامل `$` باشد.

اما:

- نباید با عدد شروع شود.
- نباید شامل فاصله باشد.
- نباید از کلمات رزروشده JavaScript استفاده کند.

---

# شیوه استاندارد نام‌گذاری

در JavaScript از **camelCase** استفاده می‌شود.

نمونه:

```javascript
firstName

userAge

totalPrice

currentAccount
```

استفاده از این شیوه باعث هماهنگی کد با استانداردهای اکوسیستم JavaScript می‌شود.

---

# اشتباهات رایج

## استفاده از نام‌های مبهم

```javascript
const x = 25;
```

بهتر است:

```javascript
const userAge = 25;
```

---

## استفاده از نام‌های بسیار طولانی

نام متغیر باید گویا باشد، اما بیش از حد طولانی نباشد.

---

## استفاده از کلمات رزروشده

نمونه زیر مجاز نیست.

```javascript
const class = "A";
```

---

# بهترین روش

هر متغیر باید دقیقاً بیان کند چه داده‌ای را نگهداری می‌کند.

اگر برای نام‌گذاری متغیر نیاز به توضیح داشته باشید، احتمالاً نام مناسبی انتخاب نکرده‌اید.

---

# خلاصه فصل

در این فصل آموختیم که:

- Value همان داده‌ای است که برنامه با آن کار می‌کند.
- Variable نامی برای دسترسی به یک مقدار است.
- از متغیرها برای خوانایی و نگهداری بهتر کد استفاده می‌شود.
- Declaration با Assignment تفاوت دارد.
- انتخاب نام مناسب برای متغیرها اهمیت زیادی در کیفیت کد دارد.

---

# گفت‌وگوی فنی

**مدیر فنی:** تفاوت Value و Variable چیست؟

**توسعه‌دهنده:** Value خودِ داده است؛ مانند عدد، رشته یا مقدار بولی. Variable یک نام است که برای نگهداری و دسترسی به آن Value استفاده می‌شود. بنابراین Variable داده نیست، بلکه مرجعی برای استفاده از داده در برنامه است.

## تحلیل

کد زیر را بررسی کنید:

```javascript
let age;

age = 18;
```

مشخص کنید کدام خط Declaration و کدام خط Assignment است.

---

## پیاده‌سازی

سه متغیر با نام‌های مناسب ایجاد کنید که اطلاعات زیر را نگهداری کنند:

- نام یک کاربر
- سن کاربر
- شهر محل زندگی کاربر

سپس مقدار هر سه متغیر را در Console نمایش دهید.
