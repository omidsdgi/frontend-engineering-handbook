# Chapter 01
# What is JavaScript?

---

# اهداف این فصل

پس از مطالعه این فصل، انتظار می‌رود بتوانید:

- JavaScript را تعریف کنید.
- نقش JavaScript را در توسعه وب توضیح دهید.
- تفاوت JavaScript با HTML و CSS را بیان کنید.
- مفهوم ECMAScript را درک کنید.
- محیط‌های اجرای JavaScript را بشناسید.
- کاربردهای امروزی JavaScript را توضیح دهید.
- چرایی محبوبیت JavaScript را تحلیل کنید.

---

# مقدمه

تقریباً هر صفحه وبی که امروز مشاهده می‌کنید، به نوعی از JavaScript استفاده می‌کند.

وقتی روی یک دکمه کلیک می‌کنید، فرمی را ارسال می‌کنید، نتایج جستجو بدون Refresh شدن صفحه نمایش داده می‌شوند یا یک اعلان روی صفحه ظاهر می‌شود، در پشت صحنه معمولاً JavaScript در حال اجرا است.

اما JavaScript فقط زبان ساخت صفحات تعاملی نیست.

امروزه با JavaScript می‌توان:

- وب‌سایت توسعه داد.
- برنامه‌های تک‌صفحه‌ای (SPA) ساخت.
- برنامه‌های سمت سرور توسعه داد.
- برنامه‌های موبایل ایجاد کرد.
- برنامه‌های دسکتاپ نوشت.
- بازی توسعه داد.
- اسکریپت‌های خودکارسازی ایجاد کرد.
- نرم‌افزارهای مبتنی بر Cloud توسعه داد.

به همین دلیل، JavaScript یکی از پرکاربردترین زبان‌های برنامه‌نویسی جهان محسوب می‌شود.

---

# JavaScript چیست؟

JavaScript یک **زبان برنامه‌نویسی سطح بالا (High-Level Programming Language)** است که برای نوشتن منطق برنامه و ایجاد تعامل در نرم‌افزارها استفاده می‌شود.

این زبان به گونه‌ای طراحی شده است که توسعه‌دهنده بتواند روی حل مسئله تمرکز کند و بسیاری از جزئیات سطح پایین، مانند مدیریت مستقیم حافظه، توسط موتور اجرای JavaScript مدیریت شوند.

---

# نقش JavaScript در صفحات وب

برای درک بهتر، سه فناوری اصلی وب را در نظر بگیرید.

| فناوری | مسئولیت |
|---------|----------|
| HTML | ساختار صفحه |
| CSS | ظاهر صفحه |
| JavaScript | رفتار و منطق صفحه |

به بیان ساده:

- HTML مشخص می‌کند چه عناصری در صفحه وجود داشته باشند.
- CSS مشخص می‌کند این عناصر چگونه نمایش داده شوند.
- JavaScript مشخص می‌کند عناصر چگونه رفتار کنند.

---

# یک مثال ساده

فرض کنید یک دکمه در صفحه دارید.

بدون JavaScript، این دکمه فقط نمایش داده می‌شود.

اما زمانی که با JavaScript رویداد کلیک را مدیریت می‌کنید، می‌تواند:

- اطلاعاتی را نمایش دهد.
- داده‌ای را ذخیره کند.
- با یک API ارتباط برقرار کند.
- صفحه را به‌روزرسانی کند.
- عملیات محاسباتی انجام دهد.

---

# JavaScript چگونه اجرا می‌شود؟

کدهای JavaScript مستقیماً توسط سیستم‌عامل اجرا نمی‌شوند.

آن‌ها توسط **JavaScript Engine** تفسیر و اجرا می‌شوند.

نمونه‌هایی از موتورهای مشهور:

| Engine | محیط |
|----------|------|
| V8 | Google Chrome و Node.js |
| SpiderMonkey | Firefox |
| JavaScriptCore | Safari |

این موتورها مسئول تبدیل کد JavaScript به دستوراتی هستند که پردازنده بتواند آن‌ها را اجرا کند.

---

# ECMAScript چیست؟

بسیاری از افراد JavaScript و ECMAScript را یکسان تصور می‌کنند، اما این دو مفهوم دقیقاً یکسان نیستند.

**ECMAScript** استاندارد رسمی زبان JavaScript است.

این استاندارد مشخص می‌کند:

- Syntax زبان چگونه باشد.
- رفتار انواع داده چگونه باشد.
- متدهای استاندارد چه عملکردی داشته باشند.
- قابلیت‌های جدید چگونه تعریف شوند.

در مقابل، JavaScript پیاده‌سازی این استاندارد است.

بنابراین:

> ECMAScript استاندارد است و JavaScript یکی از پیاده‌سازی‌های آن.

# JavaScript امروزی

در گذشته JavaScript بیشتر برای کارهای ساده داخل مرورگر استفاده می‌شد.

امروزه دامنه استفاده آن بسیار گسترده‌تر شده است.

برخی کاربردهای مهم:

- Front-End Development
- Back-End Development
- Mobile Development
- Desktop Applications
- Cloud Functions
- Automation
- Testing

---

# چرا JavaScript اهمیت دارد؟

دلایل متعددی وجود دارد.

## همه مرورگرها از آن پشتیبانی می‌کنند.

بدون نصب نرم‌افزار اضافی، هر مرورگر مدرن قادر به اجرای JavaScript است.

---

## اکوسیستم بسیار بزرگی دارد.

هزاران کتابخانه، ابزار و Framework برای JavaScript توسعه داده شده‌اند.

---

## جامعه کاربری گسترده‌ای دارد.

میلیون‌ها توسعه‌دهنده در سراسر جهان از JavaScript استفاده می‌کنند و منابع آموزشی فراوانی برای آن وجود دارد.

---

## پایه بسیاری از Frameworkهای مدرن است.

Frameworkهایی مانند React، Next.js، Vue و Angular همگی بر پایه JavaScript ساخته شده‌اند.

بنابراین، هرچه JavaScript را بهتر درک کنید، یادگیری این فناوری‌ها نیز آسان‌تر خواهد بود.

---

# تصور نادرست رایج

برخی افراد تصور می‌کنند یادگیری یک Framework مانند React به معنای یادگیری JavaScript است.

در واقع، Frameworkها بر پایه JavaScript ساخته شده‌اند.

اگر مفاهیم پایه JavaScript را به‌خوبی درک نکنید، درک رفتار Frameworkها نیز دشوار خواهد بود.

به همین دلیل، این کتاب ابتدا JavaScript را به‌صورت عمیق آموزش می‌دهد و سپس در جلدهای بعدی به Frameworkها خواهد پرداخت.

---

# خلاصه فصل

در این فصل آموختیم که:

- JavaScript زبان برنامه‌نویسی وب است.
- HTML ساختار صفحه را ایجاد می‌کند.
- CSS ظاهر صفحه را کنترل می‌کند.
- JavaScript رفتار و منطق برنامه را پیاده‌سازی می‌کند.
- ECMAScript استاندارد رسمی JavaScript است.
- JavaScript تنها محدود به مرورگر نیست و در حوزه‌های مختلف توسعه نرم‌افزار استفاده می‌شود.

# گفت‌وگوی فنی

**مدیر فنی:** JavaScript چیست؟

**توسعه‌دهنده:** JavaScript یک زبان برنامه‌نویسی سطح بالا و چندمنظوره است که برای پیاده‌سازی منطق و رفتار برنامه استفاده می‌شود. این زبان بر اساس استاندارد ECMAScript توسعه یافته و امروزه علاوه بر مرورگر، در محیط‌هایی مانند Node.js نیز اجرا می‌شود.
