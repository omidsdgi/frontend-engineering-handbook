مقدمه

در فصل قبل دیدیم که JavaScript برای کار با اعداد از Typeای به نام Number استفاده می‌کند.

با Number می‌توانیم مقدارهای عددی را ذخیره کنیم و عملیات پایه‌ای مانند جمع، تفریق، ضرب و تقسیم را انجام دهیم.

اما بسیاری از مسائل عددی فقط به Arithmetic Operatorها محدود نمی‌شوند.

فرض کنید در یک Application نیاز داریم:

یک عدد را به نزدیک‌ترین Integer تبدیل کنیم.
مقدار اعشاری را به سمت پایین یا بالا گرد کنیم.
ریشه دوم یک عدد را محاسبه کنیم.
بزرگ‌ترین مقدار یک مجموعه از اعداد را پیدا کنیم.
یک مقدار تصادفی برای یک بازی یا انتخاب تصادفی تولید کنیم.

برای چنین محاسباتی، نوشتن Logic از صفر معمولاً ضروری نیست.

JavaScript یک Object استاندارد به نام:

Math

در اختیار ما قرار می‌دهد.

Math مجموعه‌ای از Constantها و Methodهای مرتبط با محاسبات ریاضی را ارائه می‌کند.

بنابراین مسئله اصلی این فصل این نیست که چند Method را حفظ کنیم.

مسئله این است که بدانیم:

هر قابلیت Math چه مسئله‌ای را حل می‌کند و چه زمانی باید از آن استفاده کنیم؟

Math چیست؟

Math یک Object استاندارد JavaScript است که Constantها و Methodهای مختلفی برای انجام عملیات ریاضی در اختیار برنامه قرار می‌دهد.

مثلاً:

Math.sqrt(25);

نتیجه:

5

یا:

Math.max(10, 25, 7);

نتیجه:

25

نکته مهم این است که Math برای ایجاد Instance استفاده نمی‌شود.

بنابراین این کار معنای درستی ندارد:

new Math();

ما مستقیماً از Propertyها و Methodهای موجود روی Math استفاده می‌کنیم:

Math.PI
Math.round()
Math.random()

از این نظر، Math بیشتر شبیه یک مجموعه استاندارد از ابزارهای عددی است.

چرا Math به‌صورت Object ارائه شده است؟

فرض کنید بخواهیم برای هر محاسبه ریاضی یک Function جداگانه در Application خودمان بنویسیم.

برای مثال:

function calculateSquareRoot(number) {
// ...
}

function findMaximum(...numbers) {
// ...
}

function getRandomNumber() {
// ...
}

این کار باعث می‌شود Logicهایی را دوباره پیاده‌سازی کنیم که JavaScript از قبل در اختیار ما قرار داده است.

Math یک API استاندارد و شناخته‌شده برای این نوع عملیات فراهم می‌کند.

بنابراین به‌جای ساختن ابزارهای عمومی از صفر، می‌توانیم از قابلیت مناسب استفاده کنیم:

Math.sqrt()
Math.max()
Math.random()

این موضوع باعث می‌شود کد:

کوتاه‌تر باشد.
خواناتر باشد.
هدف محاسبه را واضح‌تر نشان دهد.
از پیاده‌سازی‌های تکراری جلوگیری کند.
Constants در Math

قبل از Methodها، چند مقدار ریاضی ثابت را بررسی کنیم.

Math تعدادی Constant شناخته‌شده را در اختیار برنامه قرار می‌دهد.

یکی از معروف‌ترین آن‌ها:

Math.PI

است.

Math.PI مقدار تقریبی عدد π را ارائه می‌کند:

console.log(Math.PI);

خروجی تقریباً:

3.141592653589793

این مقدار در محاسبات مرتبط با دایره کاربرد دارد.

مثلاً اگر شعاع دایره را داشته باشیم، مساحت آن از رابطه زیر به دست می‌آید:

Area = π × r²

در JavaScript:

const radius = 5;

const area = Math.PI * radius ** 2;

در اینجا Math.PI باعث می‌شود نیازی به تعریف دستی مقدار π نداشته باشیم.

Math Constantهای دیگری نیز دارد؛ مانند:

Math.E
Math.SQRT2
Math.LN2
Math.LN10

اما در Applicationهای معمول، Math.PI یکی از پرکاربردترین آن‌ها است.

Rounding

یکی از رایج‌ترین مسائل هنگام کار با اعداد، تبدیل مقدار اعشاری به Integer است.

فرض کنید قیمت یک محصول پس از محاسبه به این مقدار رسیده است:

const price = 149.7;

ممکن است در یک قسمت از Application بخواهیم آن را گرد کنیم.

اما «گرد کردن» همیشه یک رفتار مشخص ندارد.

گاهی می‌خواهیم به نزدیک‌ترین Integer برویم.

گاهی می‌خواهیم همیشه به پایین برویم.

گاهی همیشه به بالا.

و گاهی فقط بخش اعشاری را حذف کنیم.

Math برای این نیازها Methodهای متفاوتی دارد.

Math.round()

Math.round() یک عدد را به نزدیک‌ترین Integer گرد می‌کند.

مثلاً:

Math.round(4.6);

نتیجه:

5

و:

Math.round(4.4);

نتیجه:

4

پس مدل ذهنی مناسب برای Math.round() این است:

عدد را به نزدیک‌ترین Integer گرد کن.

یک نکته مهم درباره اعداد منفی وجود دارد.

Math.round(-4.5);

نتیجه:

-4

بنابراین نباید round() را صرفاً به شکل «اگر اعشار بزرگ‌تر از 0.5 بود، یک واحد اضافه کن» حفظ کنیم.

رفتار دقیق Method باید بر اساس تعریف آن تحلیل شود.

Math.floor()

Math.floor() عدد را به سمت منفی بی‌نهایت گرد می‌کند.

مثلاً:

Math.floor(4.9);

نتیجه:

4

اما در مورد عدد منفی:

Math.floor(-4.1);

نتیجه:

-5

این نکته بسیار مهم است.

floor() به معنی «حذف اعشار» نیست.

بلکه به معنی:

بزرگ‌ترین Integer کوچک‌تر یا مساوی مقدار را انتخاب کن.

به همین دلیل:

floor(4.9)  → 4
floor(-4.1) → -5
Math.ceil()

Math.ceil() در جهت مثبت بی‌نهایت گرد می‌کند.

مثلاً:

Math.ceil(4.1);

نتیجه:

5

و:

Math.ceil(-4.9);

نتیجه:

-4

بنابراین مدل ذهنی آن:

به سمت بالاترین Integer حرکت کن.

در نتیجه:

ceil(4.1)  → 5
ceil(-4.9) → -4
Math.trunc()

گاهی اصلاً نمی‌خواهیم مقدار را به نزدیک‌ترین Integer گرد کنیم.

فقط می‌خواهیم بخش اعشاری را حذف کنیم.

در این حالت:

Math.trunc(4.9);

نتیجه:

4

و:

Math.trunc(-4.9);

نتیجه:

-4

پس trunc() با floor() تفاوت مهمی دارد.

Math.floor(-4.9) → -5
Math.trunc(-4.9) → -4

علت این تفاوت این است که trunc() بخش اعشاری را حذف می‌کند و به سمت صفر حرکت می‌کند.

انتخاب Method مناسب برای Rounding

چهار Method اصلی را می‌توان این‌گونه در ذهن نگه داشت:

Method	رفتار
Math.round()	نزدیک‌ترین Integer
Math.floor()	به سمت -Infinity
Math.ceil()	به سمت +Infinity
Math.trunc()	حذف بخش اعشاری و حرکت به سمت صفر

بنابراین مسئله اصلی حفظ کردن چهار اسم نیست.

باید ابتدا مشخص کنیم:

هدف محاسبه چیست؟

اگر هدف نزدیک‌ترین Integer است:

Math.round(value);

اگر هدف حرکت به پایین‌ترین Integer است:

Math.floor(value);

اگر هدف حرکت به بالاترین Integer است:

Math.ceil(value);

اگر هدف فقط حذف اعشار است:

Math.trunc(value);

این تفاوت در محاسبات مالی، Pagination، تولید Index و بسیاری از مسائل Application اهمیت پیدا می‌کند.

Power

گاهی لازم است یک عدد را به توان مشخصی برسانیم.

مثلاً:

5² = 25

JavaScript برای این کار Operator توان نیز دارد:

5 ** 2

که نتیجه آن:

25

است.

Math نیز Methodی به نام:

Math.pow()

ارائه می‌کند.

مثلاً:

Math.pow(5, 2);

نتیجه:

25

در اینجا:

5 → Base
2 → Exponent

است.

یعنی:

5² = 25

در JavaScript مدرن، برای توان‌های معمول، Operator ** اغلب خواناتر است:

5 ** 2

اما شناخت Math.pow() همچنان مهم است، زیرا بخشی از API استاندارد Math است و ممکن است آن را در کدهای موجود مشاهده کنید.

Square Root

یکی دیگر از محاسبات رایج، محاسبه ریشه دوم است.

برای این کار از:

Math.sqrt()

استفاده می‌کنیم.

مثلاً:

Math.sqrt(25);

نتیجه:

5

زیرا:

5 × 5 = 25

در یک Application ممکن است این قابلیت برای محاسبات هندسی، فاصله، اندازه یا الگوریتم‌های عددی استفاده شود.

برای مثال، اگر فاصله دو مؤلفه را در یک سیستم مختصات دوبعدی محاسبه کنیم، ریشه دوم بخشی از فرمول فاصله خواهد بود.

نکته مهم این است که Math.sqrt() برای مقدارهای غیرمنفی نتیجه عددی معمول دارد.

مثلاً:

Math.sqrt(-1);

نتیجه:

NaN

دلیل آن این است که JavaScript در Type Number مقدارهای مختلط را نمایش نمی‌دهد.

Min و Max

تا اینجا Math را برای یک مقدار بررسی کردیم.

اما بسیاری از مسائل به چند مقدار هم‌زمان مربوط هستند.

فرض کنید قیمت چند محصول را داریم:

const prices = [120, 80, 250, 95];

اگر بخواهیم بیشترین مقدار را پیدا کنیم، می‌توانیم از:

Math.max()

استفاده کنیم.

Math.max(120, 80, 250, 95);

نتیجه:

250

برای کمترین مقدار نیز:

Math.min(120, 80, 250, 95);

نتیجه:

80

مدل ذهنی این دو Method ساده است:

Math.max() → بزرگ‌ترین مقدار
Math.min() → کوچک‌ترین مقدار
Math.max() و Array

یک نکته مهم وجود دارد.

Math.max() و Math.min() مجموعه‌ای از Argumentها را دریافت می‌کنند، نه یک Array به‌عنوان یک مجموعه.

بنابراین این کد:

const prices = [120, 80, 250, 95];

Math.max(prices);

روش صحیحی برای پیدا کردن بیشترین مقدار نیست.

برای تبدیل عناصر Array به Argumentهای جداگانه می‌توانیم از Spread Syntax استفاده کنیم:

Math.max(...prices);

نتیجه:

250

در اینجا:

...prices

باعث می‌شود عناصر Array به‌صورت Argumentهای جداگانه به Math.max() ارسال شوند.

این مثال نشان می‌دهد که مفاهیم JavaScript مستقل از یکدیگر نیستند.

Math.max() یک مسئله عددی را حل می‌کند و Spread Syntax نحوه انتقال Collection به Function را ساده می‌کند.

Random

یکی از کاربردی‌ترین قابلیت‌های Math:

Math.random()

است.

این Method یک مقدار عددی شبه‌تصادفی در بازه زیر تولید می‌کند:

0 ≤ value < 1

مثلاً:

Math.random();

ممکن است نتیجه‌ای مانند این داشته باشد:

0.374829...

یا:

0.918273...

اما هیچ‌گاه مقدار 1 را برنمی‌گرداند.

بنابراین مدل ذهنی آن:

0
↓
Math.random()
↓
less than 1

است.

چرا Math.random() مستقیماً Integer تولید نمی‌کند؟

فرض کنید در یک بازی می‌خواهیم یکی از اعداد 1 تا 6 را برای یک تاس تولید کنیم.

Math.random() به‌تنهایی کافی نیست، زیرا نتیجه آن اعشاری و در بازه 0 تا کمتر از 1 است.

ابتدا می‌توانیم آن را به بازه موردنظر منتقل کنیم:

Math.random() * 6;

اکنون نتیجه در بازه زیر قرار می‌گیرد:

0 ≤ value < 6

برای تبدیل آن به Integer از Math.floor() استفاده می‌کنیم:

Math.floor(Math.random() * 6);

در نتیجه یکی از این مقدارها تولید می‌شود:

0
1
2
3
4
5

اما تاس ما باید اعداد 1 تا 6 داشته باشد.

بنابراین یک واحد اضافه می‌کنیم:

Math.floor(Math.random() * 6) + 1;

اکنون خروجی یکی از این مقدارها است:

1
2
3
4
5
6

این الگو یکی از مهم‌ترین کاربردهای عملی Math.random() است.

تولید Integer تصادفی در یک بازه

الگوی کلی برای تولید یک Integer تصادفی بین min و max به‌صورت inclusive چنین است:

Math.floor(Math.random() * (max - min + 1)) + min;

مثلاً برای بازه 10 تا 20:

const number =
Math.floor(Math.random() * (20 - 10 + 1)) + 10;

نتیجه می‌تواند هر یک از این مقدارها باشد:

10
11
12
...
20

چرا این فرمول کار می‌کند؟

ابتدا:

Math.random()

مقداری در بازه:

0 ≤ value < 1

می‌دهد.

با ضرب در:

max - min + 1

تعداد Integerهای ممکن را ایجاد می‌کنیم.

سپس Math.floor() مقدار را به یک Integer از صفر تا تعداد موردنظر منهای یک تبدیل می‌کند.

در پایان با اضافه کردن min، بازه به محل موردنظر منتقل می‌شود.

یک مدل ذهنی برای Random Integer

برای تولید Integer تصادفی در یک بازه، سه مرحله داریم:

Random Fraction
↓
Scale
↓
Floor
↓
Shift

یعنی:

Math.floor(
Math.random() * range
) + min;

این مدل ذهنی از حفظ کردن یک فرمول بدون درک آن مفیدتر است.

Practical Calculations

اکنون می‌توانیم قابلیت‌های اصلی Math را در یک مسئله واقعی‌تر ترکیب کنیم.

فرض کنید در یک Application، اندازه یک تصویر را داریم و می‌خواهیم نسبت آن را محاسبه کنیم:

const width = 1920;
const height = 1080;

const ratio = width / height;

اگر بخواهیم مقدار را برای نمایش به دو رقم اعشار تبدیل کنیم، می‌توانیم از ترکیب محاسبات عددی و Rounding استفاده کنیم.

اما باید دقت کنیم که Math الزاماً ابزار Formatting نیست.

برای مثال:

Math.round(ratio * 100) / 100;

مقدار را از نظر عددی به دو رقم اعشار نزدیک می‌کند.

در اینجا:

ratio
↓
× 100
↓
round
↓
÷ 100

اتفاق می‌افتد.

این الگو برای برخی محاسبات ساده مفید است، اما نباید آن را با Formatting واقعی یک عدد اشتباه گرفت.

برای نمایش Locale-aware یا Formatting دقیق، قابلیت‌های دیگری مانند Intl.NumberFormat وجود دارند که در فصل مربوط به Internationalization بررسی خواهند شد.

ترکیب Math با منطق Application

ارزش واقعی Math زمانی مشخص می‌شود که آن را بخشی از Logic برنامه بدانیم.

برای مثال، فرض کنید یک سیستم امتیازدهی داریم و می‌خواهیم امتیاز نهایی را به نزدیک‌ترین Integer تبدیل کنیم:

const score = 87.6;

const finalScore = Math.round(score);

اکنون:

finalScore → 88

یا اگر یک Application نیاز داشته باشد مقدار بزرگ‌تر میان چند امتیاز را پیدا کند:

const highestScore = Math.max(72, 91, 84);

نتیجه:

91

در هر دو مثال، Math خود مسئله Application را حل نمی‌کند.

بلکه یک عملیات عددی مشخص را انجام می‌دهد.

این تفکیک مهم است:

Application Logic تصمیم می‌گیرد چه محاسبه‌ای لازم است؛ Math ابزار اجرای آن محاسبه را فراهم می‌کند.

یک نکته مهم درباره Precision

در فصل قبل دیدیم که Number در JavaScript بر اساس Floating-Point Representation کار می‌کند.

بنابراین استفاده از Math به این معنا نیست که تمام مسائل Precision از بین می‌روند.

برای مثال:

Math.round(1.005 * 100) / 100;

ممکن است نتیجه‌ای داشته باشد که با انتظار ساده انسانی از گرد کردن اعشاری متفاوت باشد.

علت این مسئله خود Math.round() نیست.

ریشه مشکل به نحوه نمایش اعداد Floating-Point در Number مربوط است.

بنابراین باید این مدل ذهنی را داشته باشیم:

Math و NaN

بعضی محاسبات ممکن است مقدار:

NaN

تولید کنند.

مثلاً:

Math.sqrt(-1);

نتیجه:

NaN

NaN به معنی این نیست که یک Exception معمولی رخ داده است.

بلکه یک مقدار خاص از Type Number است که نشان‌دهنده نتیجه نامعتبر یک عملیات عددی است.

بنابراین در Logicهای حساس باید بدانیم آیا ورودی برای محاسبه معتبر است یا خیر.

در صورت نیاز می‌توانیم از:

Number.isNaN(value)

برای بررسی آن استفاده کنیم.

Math یک Utility Object است

تا اینجا می‌توانیم تصویر کامل‌تری از Math داشته باشیم.

Math یک Object عمومی برای نگهداری ابزارهای عددی است.

این Object:

Constructor نیست.
برای ساخت Instance استفاده نمی‌شود.
State مربوط به یک Object خاص Application را نگهداری نمی‌کند.
مجموعه‌ای از Constantها و Methodهای استاندارد عددی ارائه می‌دهد.

بنابراین استفاده از آن معمولاً به این شکل است:

Math.method(...)

یا:

Math.CONSTANT

برای مثال:

Math.PI
Math.sqrt(25)
Math.max(10, 20)
Math.random()

این مدل استفاده با Objectهایی که در فصل‌های OOP برای ساخت Instance بررسی کردیم متفاوت است.

انتخاب درست Method

یکی از مهارت‌های مهم هنگام کار با Math این نیست که تمام Methodها را حفظ کنیم.

بلکه باید بتوانیم مسئله را به عملیات ریاضی مناسب تبدیل کنیم.

مثلاً اگر مسئله می‌گوید:

نزدیک‌ترین Integer را پیدا کن.

از:

Math.round()

استفاده می‌کنیم.

اگر می‌گوید:

همیشه به سمت پایین حرکت کن.

از:

Math.floor()

استفاده می‌کنیم.

اگر می‌گوید:

همیشه به سمت بالا حرکت کن.

از:

Math.ceil()

استفاده می‌کنیم.

اگر می‌گوید:

بخش اعشاری را حذف کن.

از:

Math.trunc()

استفاده می‌کنیم.

اگر می‌گوید:

ریشه دوم را محاسبه کن.

از:

Math.sqrt()

استفاده می‌کنیم.

اگر می‌گوید:

بیشترین یا کمترین مقدار را پیدا کن.

از:

Math.max()
Math.min()

استفاده می‌کنیم.

و اگر می‌گوید:

یک مقدار شبه‌تصادفی تولید کن.

از:

Math.random()

استفاده می‌کنیم.

این روش تفکر، بسیار مهم‌تر از حفظ Syntax است.

Best Practices
1. Method را بر اساس هدف محاسبه انتخاب کنید

قبل از نوشتن کد مشخص کنید که هدف:

round
floor
ceil
trunc

کدام است.

به‌خصوص برای اعداد منفی، این تفاوت‌ها اهمیت زیادی دارند.

2. Math.random() را با بازه خروجی آن در نظر بگیرید

همیشه به یاد داشته باشید:

0 ≤ Math.random() < 1

اگر به Integer نیاز دارید، باید تبدیل مناسب را انجام دهید.

3. از Math.max() و Math.min() برای مجموعه‌های کوچک و مشخص استفاده کنید

برای مجموعه‌ای از Values می‌توان از Spread استفاده کرد:

Math.max(...numbers);

اما برای Arrayهای بسیار بزرگ باید هزینه انتقال عناصر به‌عنوان Argument را نیز در طراحی در نظر گرفت.

4. Rounding را با Formatting اشتباه نگیرید

این دو مسئله متفاوت هستند:

Numeric Rounding

و:

Number Formatting

Math.round() مقدار عددی را تغییر می‌دهد.

Formatting مربوط به نحوه نمایش مقدار است.

5. محدودیت Number را فراموش نکنید

Math روی Valueهای عددی کار می‌کند.

بنابراین محدودیت‌های Number، از جمله مسائل Floating-Point Precision، همچنان وجود دارند.

اشتباهات رایج
استفاده اشتباه از floor() برای حذف اعشار

این دو یکسان نیستند:

Math.floor(-4.7);

و:

Math.trunc(-4.7);

نتیجه:

-5
-4

است.

تصور اینکه Math.random() عدد صحیح تولید می‌کند

این کد:

Math.random();

عدد اعشاری بین 0 و کمتر از 1 تولید می‌کند.

برای Integer باید آن را به بازه موردنظر تبدیل و سپس گرد کنید.

تصور اینکه Math.random() برای Security مناسب است

Math.random() برای تولید مقادیر تصادفی عمومی Application مناسب است، اما برای کاربردهای امنیتی مانند Token، Password یا موارد Cryptographic مناسب نیست.

برای چنین نیازهایی باید از APIهای مناسب Cryptographic استفاده شود.

تصور اینکه Math.max() یک Array را مستقیماً بررسی می‌کند

این:

Math.max([10, 20, 30]);

معادل استفاده صحیح برای پیدا کردن Maximum نیست.

در صورت داشتن Array می‌توان از Spread استفاده کرد:

Math.max(...[10, 20, 30]);
تصور اینکه Math مشکل Precision را حل می‌کند

Math ابزارهای محاسباتی ارائه می‌دهد، اما محدودیت‌های Floating-Point Number همچنان وجود دارند.

Methodهای Rounding رفتارهای متفاوتی دارند.

Math.round() مقدار را به نزدیک‌ترین Integer می‌برد.

Math.floor() به سمت -Infinity حرکت می‌کند.

Math.ceil() به سمت +Infinity حرکت می‌کند.

Math.trunc() بخش اعشاری را حذف می‌کند و به سمت صفر حرکت می‌کند.

برای توان می‌توان از Math.pow() و برای ریشه دوم از Math.sqrt() استفاده کرد.

Math.min() و Math.max() برای پیدا کردن کمترین و بیشترین مقدار به کار می‌روند.

Math.random() نیز یک مقدار شبه‌تصادفی در بازه 0 تا کمتر از 1 تولید می‌کند و با ترکیب آن با Math.floor() می‌توان Integerهای تصادفی در یک بازه تولید کرد.

در نهایت باید به خاطر داشت که Math محدودیت‌های Number و Floating-Point را از بین نمی‌برد.

Technical Interview
Junior
سؤال ۱ — Math چیست؟

پاسخ:

Math یک Object استاندارد JavaScript است که Constantها و Methodهای مختلفی برای انجام محاسبات ریاضی ارائه می‌کند؛ مانند Math.PI، Math.round()، Math.sqrt() و Math.random().

سؤال ۲ — آیا می‌توان از Math با new استفاده کرد؟

پاسخ:

خیر. Math یک Constructor نیست و برای ایجاد Instance طراحی نشده است. قابلیت‌های آن مستقیماً از طریق خود Object استفاده می‌شوند.

سؤال ۳ — تفاوت Math.round() و Math.trunc() چیست؟

پاسخ:

Math.round() مقدار را به نزدیک‌ترین Integer گرد می‌کند، در حالی که Math.trunc() بخش اعشاری را حذف می‌کند و به سمت صفر حرکت می‌کند.

سؤال ۴ — Math.random() چه بازه‌ای دارد؟

پاسخ:

مقداری شبه‌تصادفی در بازه زیر تولید می‌کند:

0 ≤ value < 1

بنابراین 1 هیچ‌گاه به‌عنوان نتیجه مستقیم آن برگردانده نمی‌شود.

Mid-Level
سؤال ۵ — تفاوت Math.floor() و Math.trunc() در چیست؟

پاسخ:

Math.floor() به سمت -Infinity گرد می‌کند، اما Math.trunc() بخش اعشاری را حذف کرده و به سمت صفر حرکت می‌کند. بنابراین در اعداد منفی نتایج متفاوتی دارند.

مثلاً:

Math.floor(-4.7); // -5
Math.trunc(-4.7); // -4
سؤال ۶ — چگونه یک Integer تصادفی بین 1 و 6 تولید می‌کنید؟

پاسخ:

Math.floor(Math.random() * 6) + 1;

Math.random() بازه 0 تا کمتر از 1 را ایجاد می‌کند، ضرب در 6 بازه را به 0 تا کمتر از 6 تبدیل می‌کند و Math.floor() آن را به یکی از Integerهای 0 تا 5 تبدیل می‌کند. در پایان 1 اضافه می‌شود تا بازه 1 تا 6 ایجاد شود.

سؤال ۷ — چگونه بیشترین مقدار یک Array را با Math.max() پیدا می‌کنید؟

پاسخ:

با استفاده از Spread Syntax:

const numbers = [10, 30, 20];

Math.max(...numbers);

Spread عناصر Array را به Argumentهای جداگانه تبدیل می‌کند.

سؤال ۸ — آیا Math.round() برای حل تمام مسائل Rounding مناسب است؟

پاسخ:

خیر. انتخاب Method به هدف محاسبه بستگی دارد. برای حرکت به پایین از Math.floor()، برای حرکت به بالا از Math.ceil() و برای حذف بخش اعشاری از Math.trunc() استفاده می‌شود.

Senior
سؤال ۹ — آیا استفاده از Math مشکلات Floating-Point Precision را حل می‌کند؟

پاسخ:

خیر. Math فقط عملیات ریاضی موردنیاز را ارائه می‌کند. این عملیات همچنان روی Number انجام می‌شوند و محدودیت‌های Floating-Point آن پابرجا هستند.

سؤال ۱۰ — آیا Math.random() برای تولید Token امنیتی مناسب است؟

پاسخ:

خیر. Math.random() برای Randomness عمومی Application مناسب است، اما برای نیازهای امنیتی و Cryptographic قابل اتکا نیست. برای چنین کاربردهایی باید از APIهای Cryptographic مناسب استفاده کرد.

سؤال ۱۱ — چرا Math.floor() و Math.trunc() را نباید معادل یکدیگر دانست؟

پاسخ:

زیرا جهت حرکت آن‌ها متفاوت است. Math.floor() به سمت -Infinity می‌رود، در حالی که Math.trunc() به سمت صفر حرکت می‌کند. این تفاوت برای اعداد منفی باعث نتایج متفاوت می‌شود.

سؤال ۱۲ — هنگام استفاده از Math.max(...largeArray) چه ملاحظه‌ای باید داشت؟

پاسخ:

Spread عناصر Array را به Argumentهای Function تبدیل می‌کند. برای Arrayهای بسیار بزرگ، این روش می‌تواند با محدودیت‌های مربوط به تعداد Argumentهای قابل ارسال و هزینه اجرای آن مواجه شود. در چنین شرایطی باید روش مناسب‌تری برای پیمایش و محاسبه Maximum انتخاب شود.

Golden Answers
Math چیست؟

Math یک Object استاندارد JavaScript است که مجموعه‌ای از Constantها و Methodهای ریاضی را برای انجام محاسبات عددی ارائه می‌کند.

تفاوت round، floor، ceil و trunc چیست؟

round به نزدیک‌ترین Integer می‌رود، floor به سمت -Infinity، ceil به سمت +Infinity و trunc بخش اعشاری را حذف کرده و به سمت صفر حرکت می‌کند.

Math.random() چه کاری انجام می‌دهد؟

Math.random() یک مقدار شبه‌تصادفی در بازه 0 تا کمتر از 1 تولید می‌کند. برای تولید Integer در یک بازه معمولاً با Math.floor() و یک تبدیل مقیاس ترکیب می‌شود.

آیا Math مشکلات Precision را حل می‌کند؟

خیر. Math عملیات ریاضی را فراهم می‌کند، اما محدودیت‌های Floating-Point مربوط به Number همچنان وجود دارند.

آیا Math یک Constructor است؟

خیر. Math یک Object استاندارد است و مستقیماً از طریق Propertyها و Methodهای آن استفاده می‌شود.

Conclusion
