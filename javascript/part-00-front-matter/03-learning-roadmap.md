# نقشه راه یادگیری

یکی از دلایل اصلی که بسیاری از افراد JavaScript را به‌صورت عمیق یاد نمی‌گیرند، این است که تصویر روشنی از مسیر یادگیری خود ندارند.

آن‌ها هر روز یک ویدئو می‌بینند، یک مقاله می‌خوانند یا یک پروژه جدید شروع می‌کنند، اما نمی‌دانند هر کدام از این مطالب چه ارتباطی با یکدیگر دارند و در نهایت قرار است به چه مهارتی برسند.

این کتاب با هدف حل همین مشکل طراحی شده است.

در اینجا، JavaScript را نه به‌عنوان مجموعه‌ای از قابلیت‌ها، بلکه به‌عنوان یک مسیر مهندسی یاد می‌گیریم.

---

# مسیر یادگیری این کتاب

این کتاب در چند بخش اصلی سازمان‌دهی شده است.

هر بخش بر پایه بخش‌های قبل ساخته شده و مهارت‌های جدیدی را به دانسته‌های شما اضافه می‌کند.

## بخش اول: JavaScript Fundamentals

در این بخش، پایه‌های زبان را می‌سازید.

مفاهیمی مانند:

- Values
- Variables
- Data Types
- Operators
- Expressions
- Statements
- Control Flow

در پایان این بخش می‌توانید کدهای ساده را تحلیل و اجرا کنید.

---

## بخش دوم: Functions

در این بخش یاد می‌گیرید که چرا Function قلب JavaScript است.

موضوعاتی مانند:

- Function Declaration
- Function Expression
- Arrow Function
- Parameters
- Return Value
- Scope
- Hoisting
- Closures

در پایان این بخش، رفتار توابع را به‌صورت عمیق درک خواهید کرد.

---

## بخش سوم: Behind the Scenes

این بخش یکی از مهم‌ترین فصل‌های کتاب است.

در این قسمت وارد پشت صحنه JavaScript می‌شویم و بررسی می‌کنیم که مرورگر چگونه کدهای ما را اجرا می‌کند.

مباحث این بخش شامل:

- Execution Context
- Call Stack
- Heap
- Event Loop
- Callback Queue
- Microtask Queue
- JavaScript Runtime

پس از پایان این بخش، بسیاری از رفتارهایی که قبلاً عجیب به نظر می‌رسیدند، برایتان کاملاً قابل توضیح خواهند بود.

---
