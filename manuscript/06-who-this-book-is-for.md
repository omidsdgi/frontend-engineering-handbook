# این کتاب برای چه کسانی مناسب است؟

هر کتابی برای گروه مشخصی از مخاطبان نوشته می‌شود. شناخت این موضوع به شما کمک می‌کند با انتظار درستی مطالعه را آغاز کنید.

این کتاب برای همه کسانی که با کامپیوتر کار می‌کنند نوشته نشده است؛ بلکه برای افرادی نوشته شده که می‌خواهند JavaScript را به‌صورت عمیق، کاربردی و مهندسی یاد بگیرند.

---

# این کتاب برای شما مناسب است اگر...

## می‌خواهید JavaScript را اصولی یاد بگیرید

اگر تاکنون JavaScript را به‌صورت پراکنده از ویدئوها، مقالات یا پروژه‌های مختلف یاد گرفته‌اید و احساس می‌کنید تصویر کاملی از زبان ندارید، این کتاب برای شماست.

در این کتاب مفاهیم به ترتیب و بر پایه یکدیگر آموزش داده می‌شوند تا در پایان، یک مدل ذهنی منسجم از JavaScript داشته باشید.

---

## می‌خواهید React یا Next.js را عمیق‌تر درک کنید

یادگیری React بدون شناخت JavaScript ممکن است، اما درک عمیق React بدون درک JavaScript تقریباً غیرممکن است.

بسیاری از مفاهیمی که در React استفاده می‌کنید، مانند Closure، Scope، Promise، Async/Await، Modules و Object Reference، مستقیماً از JavaScript می‌آیند.

اگر این مفاهیم را به‌خوبی بشناسید، یادگیری هر فریم‌ورک جدید بسیار ساده‌تر خواهد شد.

---

## برای مصاحبه‌های فنی آماده می‌شوید

اگر قصد دارید در مصاحبه‌های Front-End شرکت کنید، این کتاب می‌تواند یکی از منابع اصلی شما باشد.

در پایان بیشتر فصل‌ها، گفت‌وگوهای فنی، تحلیل سؤال‌های متداول و نکات مهم مصاحبه ارائه شده است تا علاوه بر یادگیری مفاهیم، بتوانید آن‌ها را به زبان ساده و دقیق توضیح دهید.

---

## در پروژه‌های واقعی کار می‌کنید

این کتاب فقط به آموزش Syntax محدود نمی‌شود.

در بسیاری از فصل‌ها بررسی خواهیم کرد که هر مفهوم در پروژه‌های واقعی چه کاربردی دارد، چه اشتباهاتی رایج است و توسعه‌دهندگان باتجربه چگونه از آن استفاده می‌کنند.

---

## به دنبال درک مفاهیم هستید، نه حفظ کردن آن‌ها

اگر هنگام یادگیری از خودتان می‌پرسید:

- چرا این قابلیت ایجاد شده است؟
- چرا JavaScript این رفتار را دارد؟
- چه مسئله‌ای با این ویژگی حل شده است؟

احتمالاً از مطالعه این کتاب لذت خواهید برد.

# این کتاب برای چه کسانی مناسب نیست؟

اگر فقط می‌خواهید در کوتاه‌ترین زمان ممکن یک پروژه آماده بسازید یا صرفاً چند دستور JavaScript را حفظ کنید، این کتاب انتخاب مناسبی نیست.

همچنین اگر به دنبال مرجعی برای تمام جزئیات APIها و متدهای زبان هستید، بهتر است در کنار این کتاب از مستندات رسمی نیز استفاده کنید.

هدف این کتاب، آموزش طرز فکر مهندسی است، نه جایگزین شدن با مستندات.
