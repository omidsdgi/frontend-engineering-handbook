# قبل از شروع

قبل از ورود به مباحث اصلی مهندسی فرانت‌اند، لازم است دیدگاه درستی نسبت به مسیر یادگیری و نحوه استفاده از این کتاب داشته باشیم.

بسیاری از افرادی که وارد دنیای برنامه‌نویسی می‌شوند، با حجم زیادی از مطالب، دوره‌ها و فناوری‌های مختلف روبه‌رو هستند.

آن‌ها ممکن است روزانه یک آموزش جدید ببینند، یک ابزار جدید یاد بگیرند یا یک پروژه جدید شروع کنند، اما همیشه این سؤال وجود دارد که هر کدام از این مطالب چه جایگاهی در مسیر یادگیری آن‌ها دارد.

این کتاب با هدف ایجاد همین دیدگاه طراحی شده است.

در این مسیر، مهندسی فرانت‌اند را نه به‌عنوان مجموعه‌ای از ابزارها، بلکه به‌عنوان یک مسیر مهندسی یاد می‌گیریم.

---

# قبل از شروع این مسیر چه چیزی باید بدانید؟

برای تبدیل شدن به یک توسعه‌دهنده حرفه‌ای Front-End، تنها یادگیری Syntax یک زبان برنامه‌نویسی کافی نیست.

توسعه نرم‌افزار ترکیبی از دانش فنی، توانایی حل مسئله، درک معماری برنامه‌ها و تجربه کار با پروژه‌های واقعی است.

قبل از شروع این کتاب بهتر است با مفاهیم پایه زیر آشنا باشید:

- ساختار اصلی HTML
- مفاهیم پایه CSS
- اصول اولیه JavaScript
- کار با مرورگر و Developer Tools
- مفاهیم ابتدایی Git
- کار با Terminal

این موارد پیش‌نیاز کامل برای شروع نیستند، اما باعث می‌شوند مفاهیم مطرح‌شده را بهتر درک کنید.

---

# چگونه این کتاب را مطالعه کنیم؟

این کتاب برای حفظ کردن دستورات یا یادگیری سریع یک فناوری خاص نوشته نشده است.

هدف اصلی، ساختن یک مدل ذهنی صحیح از نحوه کار فناوری‌های Front-End است.

برای یادگیری بهتر، هر موضوع را با این رویکرد دنبال کنید:

- ابتدا مفهوم اصلی را درک کنید.
- دلیل وجود آن مفهوم را بررسی کنید.
- رفتار آن را با مثال‌های مختلف آزمایش کنید.
- ارتباط آن را با پروژه‌های واقعی پیدا کنید.
- کدهای خود را بازبینی و بهبود دهید.

در برنامه‌نویسی، دانستن یک مفهوم با توانایی استفاده از آن تفاوت دارد.

مهارت واقعی زمانی ایجاد می‌شود که بتوانید از دانش خود برای تحلیل و حل مسئله استفاده کنید.

---

# یادگیری مفاهیم قبل از ابزارها

دنیای Front-End همیشه در حال تغییر است.

فریم‌ورک‌ها، کتابخانه‌ها و ابزارهای جدید به صورت مداوم معرفی می‌شوند. فناوری‌هایی که امروز محبوب هستند ممکن است در آینده تغییر کنند.

اما مفاهیم پایه همچنان ارزش خود را حفظ می‌کنند.

مفاهیمی مانند:

- نحوه اجرای JavaScript
- رفتار مرورگر
- مدیریت داده‌ها
- ارتباط با APIها
- ساختاردهی کد
- اصول طراحی نرم‌افزار

وابسته به یک ابزار خاص نیستند.

توسعه‌دهنده‌ای که این مفاهیم را به‌خوبی درک کرده باشد، می‌تواند فناوری‌های جدید را سریع‌تر یاد بگیرد.

---

# مانند یک مهندس فکر کنید

یک توسعه‌دهنده حرفه‌ای فقط کسی نیست که بتواند کد بنویسد.

او باید بتواند:

- مسئله را تحلیل کند.
- راه‌حل‌های مختلف را مقایسه کند.
- تصمیم‌های فنی مناسب بگیرد.
- کدی بنویسد که در آینده قابل توسعه باشد.
- دلیل انتخاب‌های خود را توضیح دهد.

هدف این کتاب فقط آموزش "چگونه کدنویسی کنیم" نیست؛ بلکه یاد می‌گیریم "چرا به این شکل کدنویسی می‌کنیم".

---

# تمرین و ساخت پروژه

یادگیری برنامه‌نویسی بدون تمرین کامل نمی‌شود.

هر مفهوم زمانی ارزشمند است که بتوانید آن را در یک پروژه واقعی استفاده کنید.

در طول مطالعه این کتاب:

- مثال‌ها را اجرا کنید.
- کدها را تغییر دهید.
- خطاها را بررسی کنید.
- پروژه‌های کوچک بسازید.
- راه‌حل‌های مختلف را آزمایش کنید.

اشتباه کردن و مواجه شدن با مشکل، بخش طبیعی مسیر یادگیری است.

---

# استفاده از مستندات

یکی از مهم‌ترین مهارت‌های یک توسعه‌دهنده حرفه‌ای، توانایی استفاده از مستندات است.

هیچ برنامه‌نویسی تمام جزئیات همه فناوری‌ها را حفظ نیست.

تفاوت اصلی در این است که یک توسعه‌دهنده حرفه‌ای می‌داند چگونه اطلاعات درست را پیدا کند و از آن استفاده کند.

منابعی مانند:

- MDN Web Docs
- مستندات رسمی JavaScript
- مستندات React
- مستندات Next.js
- مستندات ابزارهای توسعه

بخشی از فرآیند روزانه یک توسعه‌دهنده هستند.

# هدف نهایی این کتاب

هدف این کتاب فقط آشنا شدن با زبان‌ها، کتابخانه‌ها و فریم‌ورک‌ها نیست.

هدف این است که پس از مطالعه آن بتوانید:

- کدهای Front-End را بهتر تحلیل کنید.
- رفتار JavaScript را عمیق‌تر درک کنید.
- ساختار پروژه‌های واقعی را بفهمید.
- تصمیم‌های فنی بهتری بگیرید.
- برای یادگیری فناوری‌های پیشرفته‌تر آماده شوید.

این کتاب پایان مسیر یادگیری نیست؛ بلکه پایه‌ای است که تمام یادگیری‌های بعدی شما بر روی آن ساخته خواهد شد.
